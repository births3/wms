# deploy/AGENTS.override.md

`deploy/` 部署模块规则。

- 禁止提交真实密钥、`.env`、私钥、密码或生产凭据。
- 只能提交 `.example` 环境文件和占位说明。
- 真实证据必须引用开发 / 预发布环境、真实硬件或真实外部系统；禁止用 `localhost`、模拟、伪造、桩实现、示例或生产证据。
- 部署脚本默认应为预演模式，或对风险动作要求显式确认。
- 生产环境操作需要用户明确指令，并确认具体目标环境。
- 部署运行手册必须和 `justfile` 命令、验证器保持一致。
- 验证用 `just gov-t1`；Wave 证据变更还要跑相关就绪检查 / 验证命令。
