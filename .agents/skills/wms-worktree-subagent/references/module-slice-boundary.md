# 模块完整性与切片边界

用于子代理启动前和最终输出时判断：本轮是完整模块交付，还是只完成一个可合并切片。

## 判定规则

- 所有“需要=是”的行都“本轮覆盖=是”，且验证通过，才能写“模块完成”。
- 只覆盖部分需要层但验证通过，只能写“本切片可合并”。
- 任何必需验证失败、证据缺失、越权写入或业务语义待确认，都写“不可合并”。
- “不适用”必须写原因，不能用于隐藏未完成范围。
