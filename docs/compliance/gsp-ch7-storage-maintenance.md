## 关键合规链路

### 上架温区匹配（7.91）

```
M1-001 商品档案声明储存条件（冷藏/冷冻/阴凉/常温）
  ↓
M1-004 库区"温区"属性（同枚举）
  ↓
M2-005 上架时温区匹配校验（不匹配拒绝）
  ↓
M3-003 库存按温区色标分区
```

### 在库养护异常闭环（7.97/7.98/7.99）

```
M3-004 养护任务（频率可配置，默认每月 1 次）
  ↓
养护员 PDA 检查（温湿度/外观/包装）
  ↓
发现异常 → 自动创建 M-QL 联系单（类型=养护异常）
  ↓
仓库主管审批 → 处置（移库/降级/销毁）
  ↓
M3 库存状态变更（携带 approval_source = 养护异常）
```
