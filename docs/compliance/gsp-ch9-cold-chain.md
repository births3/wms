## 关键合规链路

### 冷链全程温控（冷-3 / 冷-5 / 冷-7 / 冷-8）

```
外部冷链系统（冷库 + 冷藏车 + 在途监控）
  ↓ M5-002 数据接入（v7 边界）
WMS 接收温度数据并关联订单/批次
  ↓
WMS 接收外部"温度超标事件"（M5-003）
  ↓
仓库主管在事件列表勾选要锁定的批次
  ↓
M3-003 库存隔离（携带 approval_source = 温度超标事件）
  ↓
M-QL 联系单（养护异常类型）→ 处置
  ↓
H4 通知 + 审计追踪（actor = 仓库主管）
```

### 数据保留策略（冷-9）

```
外部冷链系统持有原始温度采集数据 ≥ 5 年（GSP 主责）
  ↓
WMS 通过 M5-002 接收并缓存近 1 年（默认值，可配置）
  ↓
WMS 持有"温度超标事件"≥ 5 年（与审计追踪一致）
  ↓
GSP 检查：原始数据由外部冷链系统提供；WMS 提供事件 + 处置链路
```
