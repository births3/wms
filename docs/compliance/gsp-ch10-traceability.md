## 关键合规链路

### 追溯码全链路（追-2 / 追-3 / 追-4 / 追-6）

```
入库扫码绑定（M-TC-003 PDA）
  ↓
追溯码库登记（M-TC-002）
  ↓
出库核销（M-PK-005 + M-TC-007 装箱时扫码）
  ↓
上报"码上放心"国家追溯协同服务平台（v7 边界：WMS 直接对接）
  ↓
反查链路：追溯码 → 入库 ASN → 出库订单 → 客户 → 审计追踪（H2-002）
```

### 不合格品处置闭环（不-1 / 不-2 / 不-3）

```
发现不合格（养护异常 / 验收 / 对账 / 温度超标）
  ↓
M-QL 联系单（含 6 类审批源）
  ↓
M3-003 库存状态变更：合格 → 隔离 → 不合格
  ↓
仓库主管审批
  ↓
处置：报损扣减（M-SA）OR 销毁（待销毁状态）OR 退供（M2 退供）
  ↓
M3-003 状态：待销毁（终态）
  ↓
M6-001 报表：不合格品台账（GSP 法定）
```

### 召回响应链路（不-4）

```
药监局发布召回通知（外部）
  ↓
仓库主管在 WMS 创建 M-QL 联系单（类型=召回）
  ↓
M-TC 追溯码反查：影响的所有批号 + 客户
  ↓
M3-003 库存隔离（涉及批号全部 → 隔离状态）
  ↓
通知客户回收（H4 企微）
  ↓
回收商品按"已到货"流入退货流程（M4 退货）
  ↓
回收完成 → 销毁（M-SA 报损 + 销毁记录）
  ↓
ERP 反馈药监局（v7 边界：由 ERP 通过 EDI 报送）
```
