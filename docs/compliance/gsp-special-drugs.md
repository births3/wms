# GSP 特殊管理药品 — 合规追溯矩阵

> 章节范围：《麻醉药品和精神药品管理条例》/《医疗用毒性药品管理办法》/《放射性药品管理办法》/《疫苗管理法》/《血液制品管理条例》关联的 GSP 散落条款
> 主要覆盖模块：M1（含字典 M1-010）/ M2 入库 / M4 出库 / M-SA 报损报溢 / M-QL 销毁链路 / M6 报表 / M-VR / M-PM
> 文档层级：L4 评审/合规追溯
> 业务边界：v25 决策 — 特殊药品分类可扩展自定义；双人作业矩阵采用流程-节点二维（process × node）UI（M1-008 §11）+ 落到 M-VR 规则；ERP 不规则参数由 M-PM 规整化；未匹配触发 M-QL 联系单；销毁流程复用 M-SA 报损执行节点

## 术语对齐（v25）

| 概念 | 含义 | 例子 |
|------|------|------|
| **流程**（process）| 端到端业务对象的生命周期 | 采购入库 / 销售出库 / 报损 / 报溢 / 销毁 / 退货 |
| **节点**（node）| 流程中的关键操作环节，是双人策略的最小粒度 | 收货、验收、上架（入库流程节点）；拣货、复核（出库流程节点）；报损执行（报损流程节点）|

具体流程-节点定义见 user-stories-mvr-validation-rules.md US-VR-006 §流程-节点定义表。

## 法规依据汇总

| 法规 | 主要要求 |
|------|---------|
| 《麻醉药品和精神药品管理条例》（2016 修订）| 五专管理（专人 / 专柜 / 专账 / 专册 / 专用处方）；双人验收双人复核；专用台账日清月结；报损双人 + 主管审批；30 年保留 |
| 《医疗用毒性药品管理办法》（1988）| 专人保管；双人收货验收；专用账册逐笔登记；超剂量审批 |
| 《放射性药品管理办法》（1989）| 专库专柜；双人 + 主管审批全流程；放射防护检查记录；30 年保留 |
| 《疫苗管理法》（2019）| 全程冷链；双人验收；批次追溯到客户级；专用台账 |
| 《血液制品管理条例》（1996，2016 修订）| 专库专柜；双人作业；批号追溯到供应商和客户 |

## 关键合规链路

### 双人作业矩阵驱动链路（特-3 / 特-4 / 特-5 / 特-9）

```
M1-010 字典定义分类 + `requires_dual_person_matrix` 默认值（v25：[{process, node, policy}] 列表）
  ↓
M1-008 §11 配置中心矩阵 UI（流程 Tab + 每流程"分类×节点"矩阵）
  ↓ 保存即同步
M-VR US-VR-006 规则库（适用场景="双人策略"，条件 process × node 二维）
  ↓
业务模块在每个节点动作前调 M-VR.queryDualPersonPolicy(process, node, product_id, owner_id, warehouse_id)
  · M2-002 / M2-004 / M2-005：process=入库 + node=收货/验收/上架
  · M4-003 / M4-004 / M4-006：process=出库 + node=拣货/复核/发货交接
  · M-PK-002：process=出库 + node=装箱
  · M4-008：process=退货 + node=退货验收/退货上架
  · M-SA-001：process=报损 + node=报损执行；销毁原因码时 process=销毁
  · M-SA-002：process=报溢 + node=报溢执行
  · M-QL-004：销毁动作触发 M-SA-001 走 process=销毁 流程
  ↓
返回三档：single / dual_scan / dual_scan_with_approval
  ↓
PDA / PC 端按返回档执行：单人提交 / 双人扫码 / 双人 + 主管企业微信审批
  ↓
审计追踪记录第一/第二操作人 user_id + 命中规则 ID + 审批记录（M6-004 §2.1）
```

### 参数对照规整化链路（特-15 / 特-16）

```
ERP 推送商品档案，含字段 special_drug_category="麻醉药品(一类)"
  ↓
H8 ERP 防腐层接收
  ↓
调 M-PM US-MPM-004 map(dict_code="special_drug_category", source_value="麻醉药品(一类)")
  ↓
M-PM 按规则匹配
  ↓ 命中 → 返回 "narcotic"
        ↓ 写入 M1-001 商品档案 special_drug_category="narcotic"
        ↓ 同时记录映射溯源（rule_id + 源原值）
  ↓ 未命中 → 写入待映射队列 + 触发 M-QL"参数对照待映射"联系单
        ↓ 商品状态 = "待映射"，不可用于新 ASN
        ↓ 仓库主管处置后入库
```

### 麻精毒放专用台账链路（特-7 / 特-8 / 特-10）

```
M6-001 库存流水账（全部库存变动）
  ↓ 按 special_drug_category 字段过滤
M6-004 特殊管理药品专用台账（按分类拆分）
  ↓
每分类按法规格式输出：
  - 麻精：日清月结 + 月底结存核对
  - 毒性：进销存逐笔登记
  - 放射性：增加放射防护检查记录关联
  ↓
H9 打印模板（五栏式 PDF 法定格式）
  ↓
保留期：普通 ≥ 5 年；放射性 ≥ 30 年（H10 单独配置）
  ↓
GSP 检查现场：批量导出指定时间窗的全部分类专册（zip 包）
```
