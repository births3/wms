> 端定义：PDA=仓内手持 / PC=管理端Web / PAD=管理端平板 / H5=司机端/门店端移动页 / 后端=无UI

## 判定规则

- **豁免**：纯后端基础设施（无 UI）/ 纯 CRUD 字典（shadcn/ui 默认即可）/ 已移除占位
- **PDA**：仓内一线操作（扫码/验收/拣选/上架/盘点/养护）
- **PC**：管理端（配置/看板/报表/审批/档案管理）
- **PAD**：PC 的平板形态（包装站/复核台/月台调度大屏）
- **H5**：司机端/门店端轻量移动页
- 一个故事可能涉及多端，每端各需一个原型页
- **多端工时计算**：表中工时 = 主端工时（交互最复杂的端）；次端复用主端布局，额外增加 30% 适配工时（未计入表中，汇总时按 ×1.15 系数折算）

## 工时估算标准

| 保真度 | 单页工时 | 说明 |
|---|---|---|
| 高保真（复杂交互/多状态） | 8h | PDA 多步扫码、状态机切换、离线模式 |
| 高保真（标准） | 6h | 标准表单/列表/看板 |
| 高保真（简单） | 4h | 单一功能页 |
