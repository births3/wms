# H4 参数测试入口调整设计

## 目标

将 H4 参数设置列表工具栏中的“测试”动作移动到新增和修改共用的参数弹窗，避免测试动作脱离当前编辑上下文。

## 交互

- 参数弹窗底部依次显示“取消”“测试”“保存”。
- 点击“测试”时，先保存当前表单，再调用现有 `POST /api/v1/wechat-notify/settings/test`。
- 保存或测试期间禁用“测试”和“保存”，避免重复提交。
- 测试完成后关闭弹窗，并在页面通知区显示结果。
- 列表工具栏不再显示参数测试动作，不再使用独立测试确认弹窗。

## 边界

- 复用现有保存 mutation、测试 mutation 和测试接口，不新增后端 API。
- 测试仍只校验已保存参数的完整性和启用状态，不声明外部企业微信连通性。

## 验证

- 自检约束测试入口只能出现在参数弹窗。
- H4 Playwright E2E 验证从修改弹窗执行测试，并确认保存请求先于测试请求。
- 管理端构建和 `just gov-t1` 通过。
