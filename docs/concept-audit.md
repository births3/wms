## 数据量评估摘要

- 3 年 ~164M 行 / ~30GB（基于 Oracle 实测放大；详见 [legacy-comparison-matrix](legacy-analysis/legacy-comparison-matrix.md) §1）
- PostgreSQL 单机足够
- 不需要：分库分表 / 读写分离 / 微服务
- 需要：分级粒度分区策略（详见 [sharding-decision-matrix](infra/sharding-decision-matrix.md) v1.2）— 5 张超大表按季度 + 2 张高频日志按月 + 4 张低频中等表按年；连接池 50-100；SSD 256GB
