# M4 PC Web 出库页面设计规划

> 记录时间：2026-06-27
> 适用范围：`apps/web-admin` 的 M4 出库相关管理页
> 事实源：`docs/domain/user-stories-m4-outbound-order.md`、`docs/domain/user-stories-m4-outbound-pick.md`、`docs/domain/user-stories-m4-outbound-return.md`、`docs/domain/clarifications.md` 问题 9、10、43、48。

## 1. 目标

PC Web 端按管理型后台方案承载 M4 出库作业：左侧全局菜单、主列表、行内操作按钮、详情弹窗、写操作弹窗。页面设计只表达已落到用户故事的 M4 口径；除 C8 已确认的采购退货出库承接外，不新增其它业务流程、状态、角色、字段或接口语义。

出库页面优先覆盖主管和包装站 PC 场景；PDA 拣选、PDA 复核和离线能力仍以对应 PDA 故事为准，不迁移到 PC Web。

退货分类按 `docs/domain/clarifications.md#c8-销售退货与采购退货归类` 执行：销售退货 / 客户退货归入入库业务；M4 出库只承载采购退货 / 退供应商出库。
单据类型来源按 US-M1-011 系统字典中心执行：`dict_code = document_type`，M4 只消费 `direction = outbound` 的启用字典项；新增类型必须绑定已预置的 `workflow_template` 和 `batch_policy` 后才能创建出库单。

## 2. 页面拆分

| 页面 | 关联故事 | 目标 |
|---|---|---|
| M4 出库订单管理 | US-M4-001 | 管理 ERP 推送或手工创建的出库订单，处理校验异常、作废申请和订单详情查看。 |
| M4 波次规划 | US-M4-002、US-M4-009、US-M4-010、US-M4-011 | 管理手动/自动波次、容量上限、路径策略、出库箱规则和合并发货。 |
| M4 复核发货 | US-M4-004、US-M4-005、US-M4-006 | 管理包装站复核、随货同行单打印、快递单打印和发货交接。 |
| M4 采购退货出库 | US-M4-012 / C8 | 管理退供应商申请、审批、拣货、复核和出库交接入口。 |

## 3. 通用页面结构

1. 左侧全局菜单固定保留，当前 M4 子菜单高亮。
2. 页头只展示当前环节标题、说明和页头工具按钮。
3. 主区按“指标卡 + 筛选区 + 主列表”组织，列表是页面核心。
4. 当前环节动作放在列表行“操作”列，点击后打开弹窗。
5. 单据流程状态、订单明细、出库批号（适用时）、客户、配送和审计摘要放在“订单详情”弹窗内。
6. 页面不放常驻“当前处理单”“本环节操作”或订单明细大卡片。
7. 写操作全部通过弹窗完成，弹窗标题等于动作，说明文本带当前 WMS 出库单号或波次号。
8. PC Web 不支持离线提交；提交失败时保留表单草稿并显示错误。

## 4. 出库订单管理

面向仓库主管，处理出库订单创建、校验、异常和作废。

| 区域 | 目标内容 |
|---|---|
| 页头 | `M4 出库订单管理`；动作：刷新、打印、新建出库单、返回工作台。 |
| 指标 | 待校验、校验异常、已确认、今日新增。 |
| 列表 | WMS 单号、ERP 单号、客户/门店、要求交货日期、明细数、计划数量、状态。 |
| 订单详情弹窗 | 双单号、客户、明细、批号、数量、校验结果、流程状态、审计摘要。 |
| 列表操作 | 详情、重新校验、修改、作废申请。 |
| 写操作弹窗 | 新建出库单、修改订单、重新校验、作废申请。 |

关键规则：批号由 ERP 指定；WMS 只校验库存并决定从哪个库位拣。短拣后可继续流程，但发货前必须补拣补齐，不允许部分发货。

## 5. 波次规划

面向仓库主管，处理订单入波次、库存锁定和拣选任务下发。

| 区域 | 目标内容 |
|---|---|
| 页头 | `M4 波次规划`；动作：刷新、打印、新建波次、返回工作台。 |
| 指标 | 待下发、库存锁定、异常订单、今日完成。 |
| 列表 | 波次号、订单数、明细行数、件数、温区、路径策略、状态。 |
| 波次详情弹窗 | 波次容量、订单列表、路径策略、出库箱推荐、异常订单和流程状态。 |
| 列表操作 | 详情、下发、取消、查看拣选任务。 |
| 写操作弹窗 | 新建波次、下发波次、取消波次、调整路径策略。 |

关键规则：一个订单只能属于一个波次；波次下发后生成拣选任务；未开始拣选时允许取消或强制作废回退。

## 6. 复核发货

面向复核岗和包装站人员，处理包装站复核、打印和交接。

| 区域 | 目标内容 |
|---|---|
| 页头 | `M4 复核发货`；动作：刷新、打印、返回工作台。 |
| 指标 | 待复核、待打印、待交接、今日发货。 |
| 列表 | 出库单号、客户、复核模式、计划数量、短拣标识、配送方、状态。 |
| 订单详情弹窗 | 复核明细、追溯码核销、随货同行单、配送方、交接记录和流程状态。 |
| 列表操作 | 详情、复核、打印随货同行单、打印面单、发货交接。 |
| 写操作弹窗 | 包装站复核、打印确认、发货交接、异常备注。 |

关键规则：复核人必须与拣选人不同；复核无“不通过”，有问题按故事记录差异并走后续退回流程。M-PK 包装站基础能力按澄清 #48 延后，当前只保留与出库复核/装箱相关的接口占位和故事引用。

## 7. 采购退货出库

面向保管员、仓库主管和质量负责人，处理退供应商出库闭环。客户 / 销售退货不在本页处理，应进入入库业务。

| 区域 | 目标内容 |
|---|---|
| 页头 | `M4 采购退货出库`；动作：刷新、打印、新建采购退货单、返回工作台。 |
| 指标 | 待审批、拣货中、已发货、本页合计。 |
| 列表 | 采购退货单号、原采购入库单、供应商、退货原因、商品数、状态。 |
| 采购退货详情弹窗 | 原采购入库单、退货明细、审批记录、拣货复核记录、出库交接和流程状态。 |
| 列表操作 | 详情、审批、拣货、复核、出库交接。 |
| 写操作弹窗 | 新建采购退货单、审批、拣货、复核、出库交接。 |

关键规则：采购退货是出库动作，库存扣减和发货交接按 M4 出库规则处理；采购入库不以前置批号作为退货申请必填，销售退货的批号校验、验收和上架归入入库业务。

## 8. 组件与复用规划

| 能力 | 复用/新增方式 |
|---|---|
| 页面骨架 | 复用现有 `AppShell`、`PageHeader`、`Card`、`DataTable`、`StatusBadge`。 |
| 页面布局 | 复用 M2 入库的后台布局规则，M4 只替换页面配置、状态和动作。 |
| 详情弹窗 | 新增页面局部 `M4OutboundDetailDialog` 或等价组件，承载流程状态和明细。 |
| 动作弹窗 | 新增页面局部 `M4OutboundDialogs` 或按页面拆小弹窗；每个写操作只保留一个入口。 |
| 筛选条 | 复用 M2 `FilterBar` 模式，字段按订单、波次、复核、退货页面收窄。 |
| 数据调用 | 未来走 `apps/web-admin/src/features/outbound/*`，不得裸 `fetch`。 |
| 后端能力 | 复用 M4 service、repository、审计、幂等和库存锁定规则；缺接口或字段时先确认。 |
