## 一、方案概述

本系统是面向医药流通行业、符合 GSP 规范的仓储管理系统（WMS），覆盖**入库、库内、出库**全流程作业，并集成**电子监管码（码上放心）**、**药检单管理**、**单据套打**与**外部系统对接**能力。系统支持 PC、PAD、PDA 三端协同，系统设计遵循 GSP 规范，支持药品监管所需的关键操作可追溯。

系统由五个子系统组成：

| 子系统 | 核心价值 |
|--------|---------|
| 一、WMS 系统 | 收货到发货的全流程仓储作业管理 |
| 二、电子监管码系统 | 监管码全生命周期管理与码上放心平台自动上报 |
| 三、药检单系统 | 药检单电子化关联与对外查询 |
| 四、套打系统 | 法定单据标准化套打输出 |
| 五、接口对接系统 | 与 ERP、快递平台的数据互通 |

---

## 二、WMS 系统

### 2.1 入库作业

| 功能 | 功能说明 |
|------|---------|
| 收货 | 依据到货通知单（ASN），PDA 扫码收货，登记到货数量、批号、有效期等信息 |
| 验收 | 支持双人验收签核，记录验收结论与质量状态，全程留痕 |
| 上架 | 系统按上架策略生成上架任务，PDA 引导上架并确认库位 |

### 2.2 出库作业

| 功能 | 功能说明 |
|------|---------|
| 整件拣货 | 按订单生成整件/整托拣货任务，遵循先进先出与近效期优先 |
| 零拣拣货 | 支持拆零拣货，自动处理拆零数量与包装单位换算 |
| 整件复核 | 出库整件复核，校验数量与批号 |
| 包装站复核 | 包装站集中复核，支持称重比对（需配套电子秤硬件）与合箱作业 |

### 2.3 库内管理

| 功能 | 功能说明 |
|------|---------|
| 养护 | 养护计划制定、养护记录登记、近效期自动预警 |
| 盘点 | 盘点单生成、盘点数据录入、盘盈盘亏处理与审批 |
| 药检单管理 | 详见"三、药检单系统" |
| 库位动态优先级划分 | 基于商品出库频次（ABC 分类）自动划分库位优先级，支持仓库主管手动调整，为上架与拣货策略提供依据 |
| GSP 相关报表 | 提供购进、验收、养护、销售、出库等 GSP 法定台账报表 |
| 运营大屏 | 提供关键运营指标的可视化看板（实时数据展示）｜ *定制化驾驶舱可按需求另行约定* |

---

## 三、电子监管码系统

| 功能 | 功能说明 |
|------|---------|
| 电子监管码码库 | 监管码统一存储与分类管理，支持码与商品、批次绑定，管理单品/中包/大包码层级 |
| 入库扫描校验 | 收货扫码时自动校验监管码合法性与归属 |
| 出库扫描校验 | 出库扫码核销监管码，防止重复出库与串货 |
| 自动同步码上放心平台 | 出入库与核销事件实时上报国家"码上放心"平台 |
| 分析报表 | 提供追溯码维度的统计分析与异常预警 |

> 说明：码上放心平台对接需客户提供平台账号及接口资质，对接时间以平台开通为准。

---

## 四、药检单系统

| 功能 | 功能说明 |
|------|---------|
| 药检单扫描关联 | 扫描药检单并关联到对应收货批次与入库单 |
| 药检单对外查询 | 提供药检单对外查询能力，供下游客户随货查验 |

---

## 五、套打系统

提供标准化单据套打输出，支持自定义模板。

| 功能 | 功能说明 |
|------|---------|
| 随货同行单 | 出库随货同行单套打（GSP 法定单据） |
| 药检单 | 药检单套打输出 |
| 发票 | 发票套打输出 ｜ *发票数据来源需与贵方开票/ERP 系统对接确认* |

---

## 六、接口对接系统

| 功能 | 功能说明 |
|------|---------|
| ERP 系统对接 | 与 ERP 实现档案、单据的双向数据同步，支持字段映射与数据规整 |
| 快递接口 | 对接快递平台，实现电子面单获取、运单回传与配送方路由 |

> 说明：ERP 对接需贵方 ERP 提供接口协议与字段说明；快递对接以选定快递平台的开放接口为准。

---

## 七、范围确认事项

为确保交付范围与贵方预期一致，以下事项建议在合同/需求阶段共同确认：

1. **运营大屏**：是采用标准运营指标看板，还是需要定制化可视化驾驶舱。
2. **发票套打**：发票数据由 ERP/开票系统提供并套打，还是另有要求。
3. **药检单对外查询**：开放对象与查询渠道（下游客户/公网/内网）。
4. **监管码分析报表**：具体统计指标口径。
5. **外部对接时间**：码上放心、ERP、快递平台的接口与资质就绪时间。

## 八、合规与技术保障

| 维度 | 保障说明 |
|------|---------|
| GSP 合规 | 系统设计遵循 GSP 规范，关键操作全程可追溯 |
| 数据安全 | 操作全程审计留痕（操作人/时间），支持数据定期备份 |
| 多端协同 | PC / PAD / PDA 三端协同，PDA 支持离线作业与断网续传 |
| 权限管理 | 按角色与岗位分配操作权限，支持多组织数据隔离 |
