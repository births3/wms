# 用户故事：H5 快递对接模块

> 模块：H5 express-integration
> 性质：横向能力（出库复核/包装站完成后触发）
> 波次：Wave 4（依赖 M4 出库复核完成）
> 依赖：M4 出库、M1 商品（重量）、H1 权限、H2 审计

---

## US-H5-001：快递商配置

**作为** 系统管理员
**我要** 配置可用的快递商（顺丰/中通/圆通/京东等）及其 API 对接参数
**以便** 系统能自动推送快递单并获取运单号

### 验收标准

1. 快递商信息：名称、编码、API 地址、API Key/Secret、账号信息
2. 支持多个快递商同时启用
3. 每个快递商可配置：是否启用、优先级、适用条件
4. 快递商对接状态：已对接/测试中/停用
5. 配置变更写入审计追踪

---

## US-H5-002：快递选择规则配置

**作为** 系统管理员
**我要** 配置快递的自动选择规则（按重量/体积/地区/客户/时效等）
**以便** 出库时系统自动推荐最合适的快递商，无需人工逐单选择

### 验收标准

1. 规则维度（可组合）：
   - 按重量：< 1kg 用 A 快递，1-10kg 用 B 快递，> 10kg 用 C 快递
   - 按体积：超大件走物流专线
   - 按地区：偏远地区用指定快递
   - 按客户：VIP 客户固定用顺丰
   - 按时效：加急用顺丰，普通用中通
   - 按货主：不同货主绑定不同快递合同
2. 规则优先级：多条规则匹配时按优先级取最高的
3. 规则可设置生效时间段（如促销期间切换快递）
4. 无规则匹配时使用默认快递商
5. 规则变更写入审计追踪

---

## US-H5-003：快递单打印

**作为** 保管员（复核岗/包装站）
**我要** 在出库复核完成后一键打印快递面单
**以便** 包裹贴上面单即可交接发货

### 验收标准

1. 触发时机：出库复核通过后，在包装站/复核台操作
2. 系统按快递选择规则自动推荐快递商（可手动修改）
3. 点击"打印快递单"：
   - 调用快递商 API 下单 → 获取运单号
   - 使用打印模板引擎（US-M2-009）打印面单
4. 面单内容：运单号（条码）、寄件人、收件人（从订单客户地址取）、重量、件数
5. 运单号回写到出库订单（关联查询用）
6. 支持批量打印（同一波次多个包裹连续打印）
7. 打印失败时可重试（不重复下单，用已获取的运单号）
8. 打印记录写入审计追踪

---

## US-H5-004：快递推送（下单）

**作为** 系统（自动/手动触发）
**我要** 将包裹信息推送给快递商（电子下单），获取运单号和预计时效
**以便** 快递商提前知道有揽件需求，安排取件

### 验收标准

1. 推送信息：寄件人、收件人（姓名/电话/地址）、重量、体积、件数、备注
2. 推送时机可配置：
   - 复核完成后自动推送
   - 手动点击推送
3. 推送成功 → 获取运单号 + 预计送达时间
4. 推送失败 → 重试（可配置重试次数）；多次失败通知仓库主管
5. 支持取消快递单（发货前可取消）
6. 推送/取消记录写入审计追踪

---

## US-H5-005：快递轨迹查询

**作为** 仓库主管 / 货主
**我要** 查询已发货包裹的快递轨迹
**以便** 跟踪配送状态，处理客户查询

### 验收标准

1. 通过运单号调用快递商 API 查询轨迹
2. 轨迹信息缓存在本地（减少 API 调用，定时刷新）
3. 显示：时间、地点、状态（揽件/在途/派送中/已签收/异常）
4. 签收后自动更新出库订单状态为"已签收"
5. 异常件（退回/拒收）推送企业微信通知

---

## 跨故事约束

1. **审计追踪**：所有快递操作（下单/打印/取消/签收）写入审计表
2. **多货主**：快递费用按货主归属（3PL 计费用）
3. **幂等性**：重复推送同一包裹不重复下单（用订单号去重）
4. **打印模板**：快递面单使用 US-M2-009 打印模板引擎
5. **降级**：快递 API 不可用时不阻塞出库流程，可后续补推送
6. **企业微信通知**：推送失败/异常件通知仓库主管
