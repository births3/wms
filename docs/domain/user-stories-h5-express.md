# 用户故事：H5 快递对接模块

> 模块：H5 express-integration
> 性质：横向能力（出库复核/包装站完成后触发）
> 波次：Wave 4（依赖 M4 出库复核完成）
> 依赖：M4 出库、M1 商品（重量）、H1 权限、H2 审计

---

## US-H5-001：快递商配置

**作为** 系统管理员
**我要** 配置可用的快递商（顺丰/中通/圆通/京东等）及其 API 对接参数
**以便** 系统能自动推送快递单并获取运单号

### 验收标准

1. 快递商信息：名称、编码、API 地址、API Key/Secret、账号信息
2. 支持多个快递商同时启用
3. 每个快递商可配置：是否启用、优先级、适用条件
4. 快递商对接状态：已对接/测试中/停用
5. 配置变更写入审计追踪

---

## US-H5-002：快递选择规则配置

**作为** 系统管理员
**我要** 配置快递的自动选择规则（按重量/体积/地区/客户/时效等），并区分"自有车队 vs 第三方快递"路由
**以便** 出库时系统自动决定走哪种配送方式，无需人工逐单选择

> 业务边界提示：v10 后**配送方决策由 TMS 主管**（参 M10-004 出库订单与 TMS 协作）。本故事的"自有车队 vs 第三方快递"路由是 **TMS 不可用时的降级策略** 或 **TMS 未启用时的默认路由**。

### 验收标准

1. **配送方路由**（v10 新增 — 决定走自有车队还是第三方快递）：

| 规则维度 | 含义 | 默认 |
|---------|------|------|
| 按地区距离 | 仓库 N 公里内走自有车队（默认 50 公里），超出走第三方 | 启用 |
| 按温区 | 冷链商品优先走自有冷链车（如有）| 可选 |
| 按客户类型 | VIP 客户/连锁门店走自有车队 | 可选 |
| 按订单价值 | 高价值订单走自有车队（保密性）| 可选 |
| 按时效 | 加急订单走第三方快递（自有车队排班受限）| 可选 |
| 默认 | 无规则匹配时的默认配送方 | 第三方快递 |

2. **第三方快递规则维度**（路由到第三方快递时进一步选择具体快递商，原 v9 内容）：
   - 按重量：< 1kg 用 A 快递，1-10kg 用 B 快递，> 10kg 用 C 快递
   - 按体积：超大件走物流专线
   - 按地区：偏远地区用指定快递
   - 按客户：VIP 客户固定用顺丰
   - 按时效：加急用顺丰，普通用中通
   - 按货主：不同货主绑定不同快递合同

3. **规则优先级**：多条规则匹配时按优先级取最高的（先决定配送方，再决定具体快递商）
4. 规则可设置生效时间段（如促销期间切换快递）
5. 无规则匹配时使用默认快递商
6. **TMS 协作时本规则被覆盖**：M10-004 启用时，配送方由 TMS 决定，本规则仅作降级使用
7. 规则变更写入审计追踪

### 路由决策优先级（v10）

```
1. TMS 启用且可用？→ 配送方由 TMS 决定（M10-004）
   └─ TMS 不可用 → 本规则配送方维度判定（自有 vs 第三方）
2. 配送方 = 第三方？→ 本规则的快递商维度选择具体快递商
3. 配送方 = 自有车队？→ 跳过快递选择，进入 M4-006 自有车队装车流程
```

## US-H5-003：快递单打印

**作为** 保管员（复核岗 / 包装岗 / PDA 整件复核场景）
**我要** 在出库复核完成后一键打印快递面单（PC 端工位 OR PDA 端通过蓝牙/网络打印机）
**以便** 包裹贴上面单即可交接发货，整件直发场景不必绕回包装站

### 触发场景

| 场景 | 触发位置 | 打印机类型 |
|------|---------|----------|
| **包装站打印** | 包装站 PC + 工位 | 网络打印机（A6/A4 热敏标签机）|
| **PC 端打印** | 复核台 PC | 网络打印机 |
| **PDA 整件直发打印**（v10 新增）| PDA 整件复核完成后直接触发 | 蓝牙便携打印机（保管员随身/拣选车上）/ 网络打印机（库内 WiFi 覆盖区）|
| **PDA 零件复核打印**（v10 新增）| PDA 零件复核完成 | 同上 |

### 验收标准

1. **触发时机**：出库复核通过后，在以下任一位置操作：
   - 包装站/复核台（PC 端）
   - PDA 整件复核完成后（PDA 端，免去拿到包装站的等待）
   - PDA 零件复核完成后（PDA 端，已组合所有件后打印）

2. 系统按 H5-002 快递选择规则自动推荐快递商（可手动修改）

3. **配送方判断**：
   - 配送方=第三方快递 → 走本故事流程（打面单）
   - 配送方=自有车队 → **跳过本故事**，直接进入 M4-006 自有车队装车流程（不打面单）

4. 点击"打印快递单"：
   - 调用快递商 API 下单 → 获取运单号
   - 使用打印模板引擎（US-M2-009）打印面单

5. **PDA 触发打印分支**：
   - **打印机选择**：
     - 系统优先级：保管员个人配对的蓝牙打印机 > 当前库区登记的网络打印机 > 默认包装站打印机
     - 保管员可手动选择打印机
   - **蓝牙连接**：PDA 启动时自动尝试连接配对打印机；连接失败提示"切换到网络打印机或前往包装站"
   - **打印失败处理**：
     - 蓝牙超时（默认 10 秒）→ 提示重试 / 切换打印机
     - 已下单但打印失败 → 运单号已生成，记录到"待补打"队列，可在包装站补打（不重复下单）
   - **离线场景**：
     - 蓝牙打印机本身不需要网络
     - 但快递 API 调用需联网；离线时 PDA 暂存运单号请求，恢复后下单 + 打印（用户需在恢复后回到原订单页确认打印）

6. 面单内容：运单号（条码）、寄件人、收件人（从订单客户地址取）、重量、件数

7. 运单号回写到出库订单（关联查询用）

8. 支持批量打印（同一波次多个包裹连续打印）

9. 打印失败时可重试（不重复下单，用已获取的运单号）

10. 打印记录写入审计追踪（含触发位置：PC 端 / PDA 端 / PDA 蓝牙）

## US-H5-004：快递推送（下单）

**作为** 系统（自动/手动触发）
**我要** 将包裹信息推送给快递商（电子下单），获取运单号和预计时效
**以便** 快递商提前知道有揽件需求，安排取件

### 验收标准

1. 推送信息：寄件人、收件人（姓名/电话/地址）、重量、体积、件数、备注
2. 推送时机可配置：
   - 复核完成后自动推送
   - 手动点击推送
3. 推送成功 → 获取运单号 + 预计送达时间
4. 推送失败 → 重试（可配置重试次数）；多次失败通知仓库主管
5. 支持取消快递单（发货前可取消）
6. 推送/取消记录写入审计追踪

---

## US-H5-005：快递轨迹查询

**作为** 仓库主管 / 货主
**我要** 查询已发货包裹的快递轨迹
**以便** 跟踪配送状态，处理客户查询

### 验收标准

1. 通过运单号调用快递商 API 查询轨迹
2. 轨迹信息缓存在本地（减少 API 调用，定时刷新）
3. 显示：时间、地点、状态（揽件/在途/派送中/已签收/异常）
4. 签收后自动更新出库订单状态为"已签收"
5. 异常件（退回/拒收）推送企业微信通知

---

## 跨故事约束

1. **审计追踪**：所有快递操作（下单/打印/取消/签收）写入审计表
2. **多货主**：快递费用按货主归属（3PL 计费用）
3. **幂等性**：重复推送同一包裹不重复下单（用订单号去重）
4. **打印模板**：快递面单使用 US-M2-009 打印模板引擎
5. **降级**：快递 API 不可用时不阻塞出库流程，可后续补推送
6. **企业微信通知**：推送失败/异常件通知仓库主管
7. **通用打印失败策略**（v3.1 新增，C4；适用于本系统所有打印场景）：
   - 网络/蓝牙超时（默认 10 秒）→ 提示重试或切换打印机
   - 已生成单据但打印失败 → 记录到"待补打"队列，可后续补打，不重复生成单据
   - 缺纸/未上电 → 提示物理状态，重试上限 3 次后进入待补打队列
   - 打印记录（成功/失败/重试次数/最终状态）写入 H2 审计追踪
   - 各模块打印故事（M2-007/M2-009/M4-005/M4-009/M-PK-006）参照本策略执行，无需独立说明
8. 测试要求：写操作必须含 L4（错误路径）+ L5（数据一致）+ L8（权限）+ L11（幂等）；读操作必须含 L4 + L8

### 测试维度覆盖

#### US-H5-001 快递商配置

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 快递商 API 密钥无效 → H5_INVALID_CREDENTIALS; 重复添加同一快递商 → H5_CARRIER_DUPLICATE; 停用正在使用的快递商 → 提示"有未完成订单" |
| L5 数据一致 | 配置变更与审计记录原子写入; 停用后新订单不再分配该快递商 |
| L8 权限 | 仅系统管理员可配置; 非管理员 → 403 |
| L11 幂等 | 相同 Idempotency-Key 重复提交 → 返回首次结果 |

#### US-H5-002 快递选择规则配置

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 规则条件语法错误 → H5_RULE_INVALID; 无可用快递商匹配 → H5_NO_CARRIER_MATCH + 告警; 规则优先级冲突 → 提示确认 |
| L5 数据一致 | 规则变更后新订单立即使用新规则; 已分配的订单不受影响 |
| L8 权限 | 仅系统管理员可配置规则; 仓库主管可查看 |
| L11 幂等 | 规则配置变更支持 Idempotency-Key |

#### US-H5-003 快递单打印

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 打印机离线 → 提示"打印机不可用，请检查连接"; 面单模板缺失 → H5_TEMPLATE_NOT_FOUND; 运单号未获取 → 提示"请先推送快递下单" |
| L5 数据一致 | 打印记录与实际打印状态一致; 补打不重复生成运单号 |
| L8 权限 | 保管员（复核岗/包装岗）可打印; 其他角色 → 403 |
| L11 幂等 | 同一包裹重复打印 → 使用已有运单号（不重新下单）; 打印记录追加 |

#### US-H5-004 快递推送（下单）

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 快递商 API 返回错误 → 重试（ADR-0018 L2）; 地址不完整 → H5_ADDRESS_INCOMPLETE; 超重 → H5_WEIGHT_EXCEEDED |
| L5 数据一致 | 推送成功后运单号写入出库订单; 推送失败不影响出库流程（降级：人工填写） |
| L8 权限 | 系统自动触发无需权限; 手动触发需仓库主管/保管员权限 |
| L11 幂等 | 同一订单号重复推送 → 快递商侧去重返回已有运单号; WMS 侧用订单号去重 |

#### US-H5-005 快递轨迹查询

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 运单号不存在 → H5_WAYBILL_NOT_FOUND; 快递商 API 超时 → 返回本地缓存 + 标记"数据可能滞后" |
| L5 数据一致 | 签收状态回写与出库订单状态原子更新; 缓存数据标注最后刷新时间 |
| L8 权限 | 仓库主管查全部; 货主查本货主订单; 门店用户查本门店订单 |
| L11 幂等 | 查询天然幂等; 签收状态回写幂等（已签收不重复更新） |

### PDA 弹性

> 适用故事：US-H5-003（PDA 端快递单打印）

#### 离线策略

| 场景 | 行为 |
|------|------|
| PDA 离线时需要打印快递单 | 如本地已缓存运单号 + 面单数据 → 允许离线打印（蓝牙直连打印机）; 否则提示"需联网获取运单号" |
| 网络恢复 | 自动同步打印记录到服务端 |

#### 扫码交互

| 场景 | 行为 |
|------|------|
| 扫描包裹条码触发打印 | 扫码 → 匹配出库订单 → 获取运单号 → 打印面单 |
| 扫码无匹配 | 提示"未找到对应出库订单，请确认包裹" |

#### 异常恢复

| 场景 | 行为 |
|------|------|
| 打印中途蓝牙断开 | 记录到"待补打"队列; 重连后自动提示补打 |
| 打印后发现面单错误 | 支持作废 + 重新获取运单号 + 重打（需审计记录） |
