# 用户故事：M6 报表与审计追踪

> 模块：M6 audit-report
> 波次：Wave 4
> 依赖：H2 审计、M2 入库、M3 库存、M4 出库、M5 冷链

---

## US-M6-001：GSP 法定台账自动生成

**作为** 仓库主管
**我要** 系统自动生成 GSP 要求的法定台账
**以便** 药监检查时直接打印提交，无需手工整理

### 验收标准

1. 法定台账类型：
   - 验收记录（入库验收明细）
   - 养护记录（在库养护明细）
   - 出库复核记录（出库复核明细）
   - 库存流水账（所有库存变动）
   - 温湿度记录（冷链监控）
   - 不合格品处置记录
2. 自动从业务数据汇总生成（不需要手工录入）
3. 支持按时间范围/商品/供应商/货主筛选
4. 支持打印（使用打印模板引擎）和导出 PDF/Excel
5. 台账数据不可修改（来源于审计追踪，只读）

---

## US-M6-002：审计追踪查询

**作为** 仓库主管 / 系统管理员
**我要** 查询任意操作的完整审计记录（谁/什么时间/做了什么/旧值/新值）
**以便** 追溯问题、满足 GSP 不可篡改要求

### 验收标准

1. 查询维度：操作人、时间范围、操作类型、关联单据、商品、批号
2. 显示：操作人、时间、操作类型、旧值、新值、IP 地址、关联单据号
3. 审计数据 append-only（不可修改/删除）
4. 数据保留 ≥ 5 年
5. 支持导出

---

## US-M6-003：业务报表

**作为** 仓库主管 / 货主
**我要** 查看业务统计报表（出入库量/库存周转/效率等）
**以便** 数据驱动决策

### 验收标准

1. 报表类型：
   - 出入库日报/月报（按商品/货主/供应商）
   - 库存周转率
   - 任务效率报表（来自任务引擎绩效）
   - 近效期预警报表
   - 合规风险报表（强制通过统计）
   - 对账差异报表
2. 支持图表展示（柱状图/折线图/饼图）
3. 支持导出 Excel/PDF
4. 货主只能看自己的数据

---

## 跨故事约束

1. **审计追踪**：报表本身不产生审计（只读）
2. **多货主**：报表按货主隔离
3. **GSP 合规**：法定台账数据不可篡改
4. **打印模板**：台账打印使用 US-M2-009 模板引擎
