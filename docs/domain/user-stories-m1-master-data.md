# 用户故事：M1 基础信息与资质档案

> 模块：M1 master-data
> 依赖：H1 权限/多租户
> 关联 ADR：0001（技术栈）、0002（仓库结构）

---

## 角色清单

| 角色 | 说明 |
|------|------|
| 系统管理员 | 用户/权限/系统配置 |
| 仓库主管 | 审批、报表、异常处理 |
| 收货员 | PDA 收货、验收 |
| 养护员 | 在库养护 |
| 保管员 | 上架/拣货/复核/盘点 |
| 货主 | 查看自己的数据（3PL） |
| 门店用户 | 下单、查看配送 |
| 司机 | 签收、在途温控 |

> 角色是权限模板（默认权限集），管理员可对任何角色配置任意菜单/权限。

## US-M1-001：商品档案管理

**作为** 仓库主管
**我要** 创建和维护商品档案（编码、名称、规格、剂型、储存条件、批准文号）
**以便** 入库/出库/养护时系统能自动匹配储存要求和 GSP 规则

### 验收标准

1. 商品必填字段：编码（唯一）、名称、规格、储存条件（冷藏/冷冻/阴凉/常温）
2. 可选字段：剂型、批准文号、UDI 唯一码、电子监管码关联、生产厂家
3. 储存条件为枚举，不可自由输入
4. 编码唯一性校验（重复时提示已存在）
5. 支持编辑已有商品（不可修改编码）
6. 支持停用/启用（停用后不可用于新入库单）
7. 商品变更写入审计追踪

## US-M1-002：供应商资质档案

**作为** 仓库主管
**我要** 录入供应商信息并上传资质证照（营业执照、经营许可证、GSP 证）
**以便** 收货时系统自动校验供应商是否有权供货

### 验收标准

1. 供应商必填：名称、统一社会信用代码、联系方式
2. 资质证照：营业执照、经营许可证、GSP 证（每项含有效期）
3. 经营范围字段（文本 + 结构化标签，用于收货时匹配商品类别）
4. 有效期到期前 30 天自动预警（可配置天数）
5. 资质过期的供应商，系统拒绝其收货单创建
6. 支持上传证照图片/PDF（存对象存储）
7. 印章样张、随货同行单样张可备案
8. 供应商变更写入审计追踪

## US-M1-003：客户/门店档案

**作为** 仓库主管
**我要** 维护客户和门店信息（名称、地址、资质、经营范围）
**以便** 出库时系统校验配送合法性（如不向无资质门店配送受限药品）

### 验收标准

1. 客户必填：名称、地址、联系方式
2. 门店额外字段：经营范围、资质证照、配送地址
3. 连锁门店支持批量导入
4. 门店经营范围与商品类别关联（出库时校验）
5. 客户/门店变更写入审计追踪

## US-M1-004：仓库与库位管理

**作为** 系统管理员
**我要** 配置仓库（物理仓/逻辑仓/虚拟仓）和库位（货架-层-位）
**以便** 系统能按温区、色标、货主分配库位

### 验收标准

1. 仓库层级：物理仓 → 库区 → 库位
2. 库区属性：温区（冷藏/冷冻/阴凉/常温）、色标（合格绿/待验黄/不合格红）
3. 库位属性：编码（唯一）、容量、当前占用、所属库区
4. 支持多货主场景：库位可绑定货主或共享
5. 库位状态：可用/占用/锁定/禁用
6. 支持批量创建库位（如 A 区 01-01 到 A 区 10-05）
7. 仓库/库位变更写入审计追踪

## US-M1-005：客商开票信息

**作为** 仓库主管
**我要** 维护客户和供应商的开票信息（抬头、税号、银行信息）
**以便** 出库打印随货同行单和 3PL 计费账单时使用正确的开票信息

### 验收标准

1. 开票信息字段：发票抬头、纳税人识别号、开户行、账号
2. 一个客商可有多套开票信息（如普票/专票）
3. 开票信息变更写入审计追踪

## US-M1-006：用户与权限管理

**作为** 系统管理员
**我要** 创建用户账号、分配角色、配置角色的菜单和操作权限
**以便** 不同岗位的人只能看到和操作自己职责范围内的功能

### 验收标准

1. 用户必填：用户名（唯一）、姓名、手机号、所属角色（可多角色）
2. 角色是权限模板：每个角色有默认的菜单权限集
3. 管理员可对角色增减任意菜单/操作权限
4. 权限粒度：菜单可见性 + 按钮级操作权限（如"创建收货单"、"审批出库"）
5. 支持多货主隔离：用户可绑定货主，只能看到所属货主的数据
6. 用户停用后立即失效（token 失效）
7. 密码策略：最小长度、复杂度、过期周期（可配置）
8. 用户/角色/权限变更写入审计追踪

## US-M1-007：多货主架构

**作为** 系统管理员
**我要** 创建货主账户并配置数据隔离规则
**以便** 3PL 模式下各货主数据严格隔离，互不可见

### 验收标准

1. 货主必填：名称、编码（唯一）、联系方式、合同信息
2. 数据隔离：库存、单据、报表按货主过滤（非本货主数据不可见）
3. 库位可配置为"货主专属"或"共享"
4. 用户绑定货主后，所有查询自动加货主过滤条件
5. 系统管理员可跨货主查看（超级权限）
6. 货主间过户需审批流程（权属转移）
7. 货主变更写入审计追踪

---

## US-M1-008：系统配置

**作为** 系统管理员
**我要** 配置系统级参数（预警天数、温度阈值、审批流程开关等）
**以便** 不同仓库可按实际业务调整系统行为，无需改代码

### 验收标准

1. 配置项分类：GSP 合规参数、业务参数、通知参数
2. GSP 合规参数示例：资质预警天数（默认 30）、近效期预警月数（默认 6）、温度超标阈值
3. 业务参数示例：默认分页大小、自动上架策略、波次规划策略
4. 配置变更写入审计追踪
5. 关键 GSP 参数变更需仓库主管审批

## 跨故事约束（适用于所有 M1 用户故事）

1. **审计追踪**：所有创建/修改/删除/停用操作必须写入审计表（旧值、新值、操作人、时间）
2. **多货主**：所有数据查询默认按当前用户所属货主过滤（除系统管理员）
3. **软删除**：不物理删除数据，只标记停用/禁用
4. **双人验收**：验收签字只需两个不同用户 ID，不限角色
5. **权限可配置**：上述"作为 XX 角色"仅表示默认权限归属，实际由管理员配置决定
