## US-M1-001：商品档案管理

**作为** 仓库主管
**我要** 创建和维护商品档案（编码、名称、规格、剂型、储存条件、批准文号）
**以便** 入库/出库/养护时系统能自动匹配储存要求和 GSP 规则

**作为** 外部系统（ERP/上游平台）
**我要** 通过 API 接口批量同步商品档案
**以便** 商品主数据由上游系统统一管理，WMS 自动接收

### 验收标准

1. 商品必填字段：编码（唯一，**由 ERP 给定，WMS 不生成**）、名称、规格、储存条件（冷藏/冷冻/阴凉/常温）
2. 可选字段：剂型、批准文号、UDI 唯一码、电子监管码关联、生产厂家
3. **包装层级**：件/盒/支（或自定义层级），每级之间转换比可配置（如 1 件=10 盒，1 盒=12 支），需设置默认值
4. **物理属性**：长、宽、高（mm）、体积（cm³，可自动计算）、重量（g）
5. 储存条件为枚举，不可自由输入
4. 编码唯一性校验（重复时提示已存在）
5. 支持编辑已有商品（不可修改编码）
6. 支持停用/启用（停用后不可用于新 ASN）
7. 商品变更写入审计追踪
8. **开放 API**：提供 RESTful 接口供外部系统创建/更新/查询商品（需 API Key 鉴权）
9. **批量导入**：支持 API 批量推送 + 页面 Excel 导入

## US-M1-002：供应商资质档案

**作为** 仓库主管
**我要** 录入供应商信息并上传资质证照（营业执照、经营许可证、GSP 证）
**以便** 收货时系统自动校验供应商是否有权供货

**作为** 外部系统（ERP/采购平台）
**我要** 通过 API 接口同步供应商档案和资质信息
**以便** 供应商主数据由上游统一管理，WMS 自动接收

### 验收标准

1. 供应商必填：名称、统一社会信用代码、联系方式
2. 资质证照：营业执照、经营许可证、GSP 证（每项含有效期）
3. 经营范围字段（文本 + 结构化标签，用于收货时匹配商品类别）
4. 有效期到期前 30 天自动预警（可配置天数）
5. 资质过期的供应商，系统拒绝其收货单创建
6. 支持上传证照图片/PDF（存对象存储）
7. 印章样张、随货同行单样张可备案
8. 供应商变更写入审计追踪
9. **开放 API**：提供 RESTful 接口供外部系统创建/更新/查询供应商（需 API Key 鉴权）
10. **批量导入**：支持 API 批量推送 + 页面 Excel 导入

## US-M1-003：客户/门店档案

**作为** 仓库主管
**我要** 维护客户和门店信息（名称、多地址、资质、经营范围）
**以便** 出库时系统校验配送合法性（如不向无资质门店配送受限药品）

**作为** 外部系统（ERP/电商平台）
**我要** 通过 API 接口同步客户档案
**以便** 客户主数据由上游统一管理，WMS 自动接收

### 验收标准

1. 客户必填：名称、联系方式
2. **多地址**：一个客户可有多个收货地址（每个地址含：省市区、详细地址、联系人、电话、是否默认）
3. 门店额外字段：经营范围、资质证照、所属连锁
4. 连锁门店支持批量导入
5. 门店经营范围与商品类别关联（出库时校验）
6. 客户/门店变更写入审计追踪
7. **开放 API**：提供 RESTful 接口供外部系统创建/更新/查询客户（需 API Key 鉴权）
8. **批量导入**：支持 API 批量推送 + 页面 Excel 导入

## US-M1-004：仓库与库位管理

**作为** 系统管理员
**我要** 配置仓库（物理仓/逻辑仓/虚拟仓）和库位（排-列-层）
**以便** 系统能按温区、色标、货主分配库位

### 验收标准

1. 仓库层级：物理仓 → 库区 → 库位
2. 库区属性：温区（冷藏/冷冻/阴凉/常温）、色标（合格绿/隔离黄/不合格红）
3. **库位编码规则**：区域编码（3 位）+ 排（2 位）+ 列（2 位）+ 层（2 位），如 `A01-01-02-03` = A01 区第 01 排第 02 列第 03 层
4. 库位属性：编码（唯一）、排、列、层、**最大容积（cm³）**、当前已用容积、剩余容积（自动计算）、**最大 SKU 数**（可配置：设为 1 = 单 SKU 库位，设为 N = 多 SKU 库位）、**库位类型**（存储位/箱拣位/零拣位）、所属库区
5. 支持多货主场景：库位可绑定货主或共享
6. **库位类型说明**：
   - 存储位：大批量整件存放（通常最大 SKU 数 = 1）
   - 箱拣位：按箱拣选的库位（可多 SKU）
   - 零拣位：拆零拣选的库位（可多 SKU，补货来源为存储位）
7. 库位状态：可用/占用/锁定/停用
8. **批量创建库位**：指定区域编码 + 排范围 + 列范围 + 层范围，系统自动生成所有组合（如区域 A01，排 01-10，列 01-05，层 01-03 → 生成 150 个库位）；批量创建时可统一设置库位类型、最大容积、最大 SKU 数
8. 仓库/库位变更写入审计追踪

## US-M1-004a：容器（LPN）管理

**作为** 保管员 / 系统管理员
**我要** 统一管理所有物理容器（托盘/周转箱/出库箱/保温箱/盲标签），每个容器一个唯一 ID（LPN）全程跟踪
**以便** 任何操作（上架/移库/拣选/出库/回收）都可以"扫一个码操作整个容器"

### 验收标准

1. **容器统一为 LPN 概念**：每个物理容器一个唯一编号（LPN 码），全程跟踪位置和内容物
2. 容器类型（可扩展）：
   - 托盘（可循环，标准/非标）
   - 周转箱（可循环，仓内流转不出库）
   - 出库箱（一次性，随货发出）
   - 保温箱（可循环，冷链配送用）
   - 盲标签（一次性，顺序递增编号，轻量标识）
3. 容器属性：LPN 码（唯一）、类型、容量（体积 cm³）、状态、当前库位、所属货主
4. 容器状态：空闲 → 在用 → 在途 → 回收中（可循环类型）/ 已出库（一次性类型）
5. **内容物管理**：容器关联商品+批号+数量（一个容器可装多种商品）
6. **嵌套关系**：托盘可包含多个周转箱/出库箱；周转箱可包含商品
7. **PDA 操作**：扫 LPN 码 = 操作整个容器（含所有内容物）
   - 整托上架/移库/出库
   - 整箱拣选/出库
8. 整容器操作时，容器内所有商品的库位同步变更
9. **LPN 码生成**：由编码生成模块统一生成（盲标签为顺序递增）
10. 容器标签支持打印（含 LPN 码条码/二维码 + 内容物摘要）
11. **回收追踪**（可循环类型）：出库后跟踪回收状态
12. 容器全生命周期写入审计追踪（创建/装箱/拆箱/移动/出库/回收）

## US-M1-006：用户与权限管理

**作为** 系统管理员
**我要** 创建用户账号、分配角色、配置角色的菜单和操作权限
**以便** 不同岗位的人只能看到和操作自己职责范围内的功能

### 验收标准

1. 用户必填：用户名（唯一）、姓名、手机号、所属角色（可多角色）
2. 角色是权限模板：每个角色有默认的菜单权限集
3. 管理员可对角色增减任意菜单/操作权限
4. 权限粒度：菜单可见性 + 按钮级操作权限（如"创建收货单"、"审批出库"）
5. 支持多货主隔离：用户可绑定货主，只能看到所属货主的数据
6. 用户停用后立即失效（token 失效）
7. 密码策略：最小长度、复杂度、过期周期（可配置）
8. 用户/角色/权限变更写入审计追踪

## US-M1-007：多货主架构

**作为** 系统管理员
**我要** 创建货主账户并配置数据隔离规则
**以便** 3PL 模式下各货主数据严格隔离，互不可见

### 验收标准

1. 货主必填：名称、编码（唯一）、联系方式、合同信息
2. 数据隔离：库存、单据、报表按货主过滤（非本货主数据不可见）
3. 库位可配置为"货主专属"或"共享"
4. 用户绑定货主后，所有查询自动加货主过滤条件
5. 系统管理员可跨货主查看（超级权限）
6. 货主间货主转换需审批流程（权属转移）
7. 货主变更写入审计追踪

## US-M1-008：系统配置中心

**作为** 系统管理员
**我要** 在统一的配置中心管理所有业务参数，支持分类浏览、搜索、配置向导、变更审计
**以便** 不同仓库可按实际业务调整系统行为，无需改代码

### 验收标准

1. **配置分类**（按业务域分组展示）：

| 分类 | 配置项数 | 示例 |
|------|---------|------|
| 入库流程 | 4 | 追溯码录入环节、上架模式、双人签字时机、上架策略优先级 |
| 出库流程 | 7 | 波次触发方式、波次分组规则、拣选路径策略、出库箱规则、库存扣减时机、复核方式、合并发货条件 |
| 补货 | 4 | 阈值统计天数、安全系数、检查频率、补货数量单位 |
| 任务引擎 | 5 | 优先级排序、分配策略、最大并行数、超时阈值、合并开关 |
| 库存管理 | 6 | 近效期预警天数、盘点差异阈值、ABC 阈值、ABC 重算频率、库位最大 SKU 数、效期隔离 |
| 包装站 | 2 | 称重偏差阈值、保温箱蓄冷剂规则 |
| 冷链 | 3 | 温度采集频率、温度超标阈值、设备校准预警天数 |
| 对账 | 2 | 对账频率、差异锁定阈值 |
| 计费 | 2 | 仓储费计算方式、账单生成日 |
| 通知 | 2 | 事件通知映射、审批超时时间 |
| 监管 | 2 | 上报频率、重试次数 |
| 多仓/连锁 | 4 | 默认仓库、跨仓可见性、门店补货统计天数、越库条件 |

2. **所有配置项有合理默认值**（开箱即用，无需配置即可运行）
3. **配置向导**：首次部署时引导用户确认关键配置（分步骤，可跳过用默认值）
4. **分级展示**：常用配置直接显示，高级配置折叠（点击展开）
5. **搜索**：支持按关键词搜索配置项
6. **配置作用域**：全局配置 / 仓库级配置 / 货主级配置（优先级：货主 > 仓库 > 全局）
7. **配置预览**：修改策略类配置前可模拟预览影响（如改上架策略后模拟推荐结果）
8. **GSP 参数保护**：GSP 合规相关参数变更需仓库主管审批
9. **配置导入导出**：支持 JSON 导入导出（方便多仓复制配置）
10. 所有配置变更写入审计追踪（旧值/新值/操作人/时间/原因）

## US-M1-009：多仓管理

**作为** 系统管理员
**我要** 配置多个仓库，用户登录后选择/切换当前操作仓库
**以便** 一套系统管理多个物理仓库，数据按仓库隔离

### 验收标准

1. **仓库定义**：编号、名称、地址、类型（常温仓/冷库/阴凉库）、状态（启用/停用）
2. **仓库切换**：用户登录后选择当前仓库，所有操作在当前仓库上下文内
3. **数据隔离**：库存/库位/任务/订单按仓库隔离
4. **跨仓可见**：仓库主管可查看所有仓库的汇总数据（权限控制）
5. **库间调拨**：M3 US-M3-007 已覆盖（调拨 = 源仓出库 + 目标仓入库）
6. **用户权限**：用户可绑定多个仓库（有权操作哪些仓库）
7. 仓库配置变更写入审计追踪

## 跨故事约束（适用于所有 M1 用户故事）

1. **审计追踪**：所有创建/修改/删除/停用操作必须写入审计表（旧值、新值、操作人、时间）
2. **多货主**：所有数据查询默认按当前用户所属货主过滤（除系统管理员）
3. **软删除**：不物理删除数据，只标记停用/禁用
4. **双人验收**：验收签字只需两个不同用户 ID，不限角色
5. **权限可配置**：上述"作为 XX 角色"仅表示默认权限归属，实际由管理员配置决定
