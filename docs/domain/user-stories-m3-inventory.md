# 用户故事：M3 库存与质量管控

> 模块：M3 inventory
> 依赖：M1 基础档案、M2 入库、H1 权限、H2 审计
> 关联 ADR：0001、0006（TDD）

---

## US-M3-001：实时库存查询

**作为** 仓库主管（或货主）
**我要** 按商品/批号/库位/货主/温区等维度查询当前库存
**以便** 随时掌握库存全貌，支撑出库决策和补货计划

### 验收标准

1. 查询维度：商品、批号、库位（排-列-层）、库区、温区、货主、库存类型
2. 显示字段：商品信息、批号、生产日期、有效期、数量、库位、货箱/托盘、库存类型
3. 支持组合筛选 + 模糊搜索
4. 支持导出 Excel
5. 货主只能看到自己的库存（多租户隔离）
6. 实时性：库存变动后查询立即反映（无延迟缓存）
7. 支持 API 查询（供外部系统调用）

## US-M3-002：批次与效期管理

**作为** 系统（自动规则）
**我要** 对所有库存按批号+效期管理，自动执行 FIFO / 近效期先出
**以便** 确保出库时优先消耗近效期商品，避免过期损失和 GSP 违规

### 验收标准

1. 每条库存记录必须关联：批号、生产日期、有效期
2. **FIFO 规则**：出库分配时自动按入库时间先进先出
3. **近效期先出**：同商品多批次时，优先分配效期最近的批次
4. **近效期预警**：距过期 < N 个月（可配置）的批次自动标记"近效期"
5. **过期锁定**：到达有效期的批次自动变为"不合格"状态，锁定不可出库
6. 近效期/过期预警推送通知（仓库主管）
7. 批次追溯：输入批号可查看该批次的完整流转记录（入库→库位→出库→客户）

## US-M3-003：库存类型管理

**作为** 仓库主管
**我要** 管理库存的质量状态（正品/待验/不合格/退货/冻结/待销毁）
**以便** 不同状态的库存存放在对应色标区域，且只有正品可出库

### 验收标准

1. 库存类型枚举：正品（合格）、待验、不合格、退货、冻结（锁库）、待销毁
2. 类型与色标对应：正品→绿区、待验→黄区、不合格→红区
3. **只有"正品"状态的库存可被出库分配**
4. 类型变更必须有原因和审批：
   - 待验 → 正品：需验收合格结论
   - 待验 → 不合格：需验收不合格结论
   - 正品 → 冻结：需仓库主管审批（如质量投诉、召回）
   - 不合格 → 待销毁：需质量审批
5. 冻结操作立即生效（锁定库存，不可出库/移库）
6. 所有类型变更写入审计追踪

## US-M3-004：在库养护

**作为** 养护员
**我要** 按养护计划对在库商品进行定期检查，记录养护结果
**以便** 满足 GSP 在库养护要求，及时发现质量异常

### 验收标准

1. **养护计划自动生成**：
   - 重点养护品种：每月一次（如生物制品、冷链药品）
   - 一般品种：每季度一次
   - 计划生成规则可配置
2. 养护任务推送到养护员 PDA
3. PDA 养护记录：温湿度、外观、包装、虫害、鼠害、霉变
4. 养护结论：正常 / 异常
5. **异常闭环处置**：养护异常 → 自动生成异常处置单 → 仓库主管审批 → 处置（移库/降级/销毁）
6. 养护记录不可修改（append-only）
7. 养护完成率统计（已养护 / 应养护）
8. 逾期未养护自动预警

## US-M3-005：库存盘点

**作为** 保管员
**我要** 在 PDA 上执行盘点任务（循环盘/全盘/盲盘），录入实盘数量
**以便** 核实系统库存与实物一致，发现差异及时处理

### 验收标准

1. 盘点类型：
   - **循环盘点**：按库区/商品类别轮流盘，不停业
   - **全盘**：全仓一次性盘点（通常年度）
   - **盲盘**：PDA 不显示系统数量，保管员录入实盘数后系统对比
2. 盘点任务创建：仓库主管指定范围（库区/商品/货主）→ 生成盘点单
3. PDA 执行：扫库位码 → 扫商品码 → 录入实盘数量
4. 盘点差异自动计算：盘盈 / 盘亏 / 无差异
5. **差异审批流程**：
   - 盘盈：需仓库主管审批 → 审批通过后库存增加
   - 盘亏：需仓库主管审批 → 审批通过后库存减少
   - 差异超过阈值（可配置）需更高级别审批
6. 盘点锁定：盘点进行中的库位/商品暂停出库分配
7. 盘点记录写入审计追踪
8. 盘点报告可打印

## US-M3-006：库内移库

**作为** 保管员
**我要** 在 PDA 上将商品从一个库位移动到另一个库位
**以便** 优化库位利用率或配合温区调整

### 验收标准

1. PDA 操作：扫源库位 → 扫商品/货箱/托盘 → 扫目标库位 → 确认
2. 移库时校验目标库位：温区匹配、色标匹配、容量足够
3. 不合法目标库位拒绝移入（如冷藏品移到常温区）
4. 支持整托移库（扫托盘码 = 移动整托）
5. 支持整箱移库（扫货箱码 = 移动整箱）
6. 移库后源库位库存减少、目标库位库存增加（同一事务）
7. 移库记录写入审计追踪

---

## US-M3-007：跨仓调拨

**作为** 仓库主管
**我要** 创建调拨单将库存从一个仓库转移到另一个仓库
**以便** 平衡各仓库库存或满足区域配送需求

### 验收标准

1. 调拨单必填：源仓、目标仓、商品明细（商品+批号+数量）
2. 调拨状态：草稿 → 已审批 → 出库中 → 在途 → 已入库
3. 源仓出库：扣减源仓库存，生成调拨出库记录
4. 目标仓入库：增加目标仓库存，生成调拨入库记录
5. 在途库存可查询（属于源仓但已出库、目标仓未入库）
6. 调拨需仓库主管审批
7. 冷链商品调拨需记录运输温度
8. 调拨全流程写入审计追踪

---

## US-M3-008：货主间过户

**作为** 仓库主管
**我要** 将库存从一个货主名下转移到另一个货主名下（权属转移）
**以便** 支持 3PL 场景下的货权变更（如货主间交易）

### 验收标准

1. 过户单必填：源货主、目标货主、商品明细（商品+批号+数量）
2. 过户需双方货主确认 + 仓库主管审批（三方）
3. 过户后：源货主库存减少、目标货主库存增加（物理位置不变）
4. 过户不产生物理移动（库位不变，只变权属）
5. 过户记录写入审计追踪
6. 过户后计费归属变更（3PL 计费模块消费）

---

## US-M3-009：库存预警

**作为** 仓库主管
**我要** 系统自动监控库存异常并推送预警
**以便** 及时处理近效期、超储、缺货等风险

### 验收标准

1. 预警类型：
   - **近效期预警**：距过期 < N 月（可配置）
   - **过期预警**：已到期未处置
   - **安全库存预警**：低于最低库存水位
   - **超储预警**：超过最高库存水位
   - **养护逾期预警**：超过养护周期未养护
   - **温湿度超标预警**：（关联 M5 冷链）
2. 预警推送方式：系统消息 + 可选短信/邮件（可配置）
3. 预警状态：待处理 → 已处理 / 已忽略
4. 预警处理记录写入审计追踪
5. 预警统计看板（按类型/商品/货主汇总）

## 跨故事约束（适用于所有 M3 用户故事）

1. **审计追踪**：所有库存变动（增/减/移/冻结/类型变更/过户）必须写入审计表
2. **多货主**：库存按货主隔离，查询/操作自动过滤
3. **库存变更必须经领域服务**：禁止直接 SQL 修改库存（红线）
4. **事务一致性**：移库/调拨/过户的"减+增"必须在同一事务内
5. **幂等性**：所有写操作支持 Idempotency-Key
6. **FIFO/近效期先出**：出库分配时系统强制执行，不可人工跳过（除非仓库主管审批豁免）
7. **PDA 离线**：移库/盘点支持离线暂存
8. **开放 API**：库存查询、调拨创建支持外部系统调用
