## US-M5-001：冷链设备台账

**作为** 仓库主管
**我要** 管理冷库、冷藏车、保温箱、计量器具的验证报告和校准周期
**以便** 满足 GSP 冷链设备管理要求

### 验收标准

1. 设备类型：冷库、冷藏车、保温箱、温度计、温湿度记录仪
2. 设备属性：编号、名称、型号、安装位置、验证报告（附件）、校准周期
3. **设备数据来源**：可手工录入（基础设备）或从外部冷链系统接口同步（推荐）
4. 校准到期预警（**默认提前 30 天**，可配置）→ 企业微信通知（H4）
5. 验证报告上传（PDF/图片，对象存储）
6. 设备变更写入审计追踪

## US-M5-002：温控数据接入与展示

**作为** 仓库主管
**我要** 查看由外部冷链系统推送的温湿度数据，并将温控曲线/报告关联到出库订单
**以便** GSP 检查时直接提供温控证据，无需切换系统

### 验收标准

1. **数据来源**：外部冷链系统通过 H8 防腐层接口（"冷链系统 → WMS" 通道）推送温湿度数据
2. **接收数据结构**：温度、湿度、采集时间、设备编号、关联库区/车辆、超标标志（外部系统判定）
3. **展示**：
   - 按库区/车辆/时间段展示温湿度曲线（前端绘图，数据从 WMS 本地缓存读，温度区间见 M1 附录 A 储存条件温度区间表）
   - 标注超标区间（红色高亮，超标判定由外部系统给出）
4. **导出 PDF 报告**：曲线图 + 超标记录 + 设备信息（使用 H9 打印模板引擎）
5. **关联出库订单**：报告可绑定出库订单（随货提供温控证据）
6. **温控报告二维码**：打印在随货同行单上，扫码跳转外部冷链系统的在线报告链接（链接由外部系统提供）
7. 数据保留与外部冷链系统协调：WMS 缓存近 1 年（用于查询），更长保留由外部系统负责（GSP ≥ 5 年）
8. 接收/展示/导出记录写入审计追踪

## US-M5-003：温度超标事件接入与联动

**作为** 系统（接收外部冷链系统事件）
**我要** 在外部冷链系统判定温度超标时接收事件并联动 WMS 业务（如批次隔离/通知主管）
**以便** 超标事件能直接驱动库存状态变更，闭环 GSP 合规

### 验收标准

1. **事件接入**：外部冷链系统通过 H8 防腐层接口推送"温度超标事件"（含设备编号/库区/超标时间段/最高最低值/影响批次）
2. **超标事件联动**：
   - 影响批次自动进入"温度超标待处置"列表
   - 推送企业微信通知仓库主管（H4）
   - 仓库主管在差异列表勾选要锁定的批次（类似 M-RC 对账差异处理）→ 触发 M3 库存隔离，携带 `approval_source = 温度超标事件, approval_id = 外部冷链系统事件 ID`（见 M3-003 审批源枚举）
3. **不自动隔离**：避免外部系统误报导致大面积冻结业务（与 M-RC 决策一致）
4. **超时机制**：事件未处置超过 4 小时 → 升级通知（企业微信 + 短信）
5. **降级策略**：外部冷链系统不可用时，超标事件无法接收，WMS 业务不阻塞（但需在系统看板显示"冷链系统离线"警示）
6. 事件接收/处置全流程写入审计追踪

---

## 跨故事约束（适用于所有 M5 用户故事）

1. **审计追踪**：所有事件接收/设备变更/超标处置写入审计表
2. **业务边界**：WMS 不采集温度、不判定超标、不持有 ≥5 年温控原始数据；这些由外部冷链系统负责
3. **GSP 合规**：超标事件接入后必须有处置闭环（隔离/报告关联到出库订单等）；GSP 检查时通过外部冷链系统获取完整温控数据
4. **企业微信通知**：超标事件、设备校准到期通知
5. **多货主**：冷链数据按库区关联货主
6. **幂等性**：外部系统重复推送同一事件不重复处理（通过事件 ID 去重）

### 测试维度覆盖

#### US-M5-001 冷链设备台账

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 设备编号重复 → M5_DEVICE_DUPLICATE; 设备类型不在枚举内 → M5_INVALID_DEVICE_TYPE; 停用有活跃监控的设备 → 提示"请先停止监控" |
| L5 数据一致 | 设备状态与监控数据接入一致; 停用后不再接收该设备数据 |
| L8 权限 | 仓库主管可管理; 养护员只读 |
| L11 幂等 | 创建/修改支持 Idempotency-Key |

#### US-M5-002 温控数据接入与展示

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 外部冷链系统推送格式错误 → M5_DATA_FORMAT_INVALID; 设备不存在 → M5_DEVICE_NOT_FOUND; 数据时间戳异常（未来时间）→ M5_INVALID_TIMESTAMP |
| L5 数据一致 | 接收数据与展示数据一致; 数据按时间序列存储不丢不重 |
| L8 权限 | 外部系统通过 API Key 推送; 仓库主管/养护员可查看; 货主查本货主库区 |
| L11 幂等 | 同一设备 + 同一时间戳重复推送 → 去重（不重复存储） |

#### US-M5-003 温度超标事件接入与联动

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 超标事件关联库区不存在 → M5_ZONE_NOT_FOUND; 联动创建 M-QL 联系单失败 → 重试 + 告警; 超标阈值配置缺失 → 使用默认阈值 + 告警 |
| L5 数据一致 | 超标事件与批次隔离联动原子; 超标记录与 M-QL 联系单关联 |
| L8 权限 | 系统自动触发; 仓库主管可查看/处理; 养护员可确认 |
| L11 幂等 | 同一设备 + 同一时间窗 + 同一超标类型 → 不重复创建事件 |

### PDA 弹性

> 适用故事：US-M5-003（PDA 端温度超标确认）

#### 离线策略

| 场景 | 行为 |
|------|------|
| PDA 离线时收到超标告警 | 通过企业微信 APP 推送（不依赖 WMS PDA 在线） |
| PDA 离线时确认超标处理 | 暂存确认记录; 网络恢复后同步 |

#### 扫码交互

| 场景 | 行为 |
|------|------|
| 扫描冷链设备码 | 显示该设备最近温湿度数据 + 超标历史 |
| 扫描库位码 | 显示该库位关联的冷链设备 + 当前温度 |

#### 异常恢复

| 场景 | 行为 |
|------|------|
| 超标确认同步失败 | 本地保留; 自动重试; 服务端幂等去重 |
