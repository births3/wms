# 用户故事：M5 冷链基础管控

> 模块：M5 cold-chain
> 波次：Wave 4
> 依赖：M1 基础档案、M3 库存、H2 审计、H4 企业微信

---

## US-M5-001：温湿度采集

**作为** 系统（自动）
**我要** 对接冷库/冷藏车温湿度探头，实时采集并存储温湿度数据
**以便** 全程监控冷链环境，超标时及时预警

### 验收标准

1. 对接方式：探头/网关 API（HTTP/MQTT），采集频率可配置（默认每 5 分钟）
2. 存储：温度、湿度、采集时间、设备编号、关联库区/车辆
3. 超标预警：实测值超出储存条件允许范围 → 企业微信通知仓库主管
4. 预警记录：超标时间、持续时长、最高/最低值
5. 数据保留 ≥ 5 年（GSP 要求）
6. 采集记录写入审计追踪

---

## US-M5-002：冷链台账

**作为** 仓库主管
**我要** 管理冷库、冷藏车、保温箱、计量器具的验证报告和校准周期
**以便** 满足 GSP 冷链设备管理要求

### 验收标准

1. 设备类型：冷库、冷藏车、保温箱、温度计、温湿度记录仪
2. 设备属性：编号、名称、型号、安装位置、验证报告（附件）、校准周期
3. 校准到期预警（提前 N 天，可配置）→ 企业微信通知
4. 验证报告上传（PDF/图片）
5. 设备变更写入审计追踪

---

## US-M5-003：温控曲线与报告

**作为** 仓库主管
**我要** 查看任意时间段的温湿度曲线图，并导出温控报告
**以便** GSP 检查时提供温控证据

### 验收标准

1. 曲线图：按库区/车辆/时间段展示温湿度变化
2. 标注超标区间（红色高亮）
3. 导出 PDF 报告（含曲线图 + 超标记录 + 设备信息）
4. 报告可关联到出库订单（随货提供温控证据）
5. 温控报告二维码：打印在随货同行单上，扫码可查看在线报告

---

## 跨故事约束

1. **审计追踪**：所有采集/预警/设备变更写入审计表
2. **GSP 合规**：数据保留 ≥ 5 年；设备必须有验证报告
3. **企业微信通知**：温度超标、设备校准到期通知
4. **多货主**：冷链数据按库区关联货主
