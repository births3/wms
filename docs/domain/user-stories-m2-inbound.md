# 用户故事：M2 采购入库作业

> 模块：M2 inbound
> 依赖：M1 基础档案、H1 权限、H2 审计、H3 OpenAPI
> 关联 ADR：0001、0006（TDD）

---

## US-M2-001：创建收货通知单（ASN）

**作为** 仓库主管（或外部系统通过 API）
**我要** 创建收货通知单（ASN），登记预计到货的供应商、商品、数量、预计到货时间
**以便** 收货员提前知道今天要收什么货，做好准备

### 验收标准

1. ASN 必填：供应商、预计到货时间、商品明细（商品+批号+数量+生产日期+有效期）
2. ASN 单号：系统自动生成（规则可配置），全局唯一
3. 创建时自动校验供应商资质是否在有效期内（过期则拒绝创建）
4. 创建时自动校验供应商经营范围是否覆盖所有商品类别（不匹配则拒绝）
5. ASN 状态：草稿 → 已确认 → 收货中 → 已完成 → 已关闭
6. **ASN 作废**：状态为"草稿"或"已确认"（未开始收货）时可申请作废，需仓库主管审批；收货中/已完成不可作废
7. **开放 API**：支持外部系统通过 API 推送 ASN（ERP/采购系统，API Key 鉴权）
7. 支持手工创建（页面录入）
8. **ASN 打印**：支持打印 ASN 单据（含 ASN 单号条码，供 PDA 扫码用）
9. ASN 创建/修改写入审计追踪

## US-M2-002：PDA 扫码到货签收

**作为** 收货员
**我要** 在 PDA 上通过多种方式查找 ASN 并签收到货
**以便** 记录实际到货时间、送货人、冷链温度等关键信息

### 验收标准

1. **PDA 查找 ASN 的方式**（任选其一）：
   - 扫 ASN 单号条码 → 直接定位到该 ASN
   - 扫电子监管码 → 解析出商品信息 → 查询该商品对应的未收货 ASN 列表 → 选择
   - 手工输入 ASN 单号查询
2. 签收时必须录入：
   - 实际到货时间
   - 送货人姓名
   - 送货人授权委托书编号（如有）
   - 冷链商品：启运温度、到货温度、运输时长
3. 冷链温度超标时系统弹出警告，收货员可选择"拒收"或"标记异常继续"
4. 签收后 ASN 状态变为"收货中"
5. 支持部分到货（实收数量 ≤ ASN 数量）
6. 签收信息写入审计追踪
7. **离线支持**：PDA 断网时可暂存签收数据，恢复后自动同步

## US-M2-003：PDA 逐件验收（扫电子监管码）

**作为** 收货员
**我要** 在 PDA 上扫电子监管码进行逐件验收，系统自动获取批号、数量等信息
**以便** 确认每件商品的身份、数量、外观、包装完好

### 验收标准

1. **PDA 扫电子监管码** → 系统自动解析/查询获取：商品编码、批号、生产日期、有效期、数量
2. 如果电子监管码无法解析（码损坏/未录入）→ 手工录入批号/效期/数量
3. 扫码后自动匹配当前 ASN 明细行（按商品+批号匹配）
4. 验收时记录：外观（完好/破损）、包装（完好/破损）、数量
5. 近效期商品自动预警（距过期 < 配置月数）
6. 已过期商品自动标记为"不合格"，不允许入库
7. 验收进度实时显示（已验 / 总数）
8. **离线支持**：断网时暂存验收数据

## US-M2-004：双人验收签字

**作为** 收货员 A 和收货员 B（任意两个不同用户）
**我要** 对同一批收货进行双人验收签字
**以便** 满足 GSP 双人验收要求，确保验收结论可靠

### 验收标准

1. 验收结论：合格 / 不合格 / 待验（需进一步检验）
2. 必须两个**不同用户 ID** 签字后，验收结论才生效
3. 第一人签字后状态为"待第二人签字"
4. 第二人签字后状态流转：
   - 合格 → 可上架
   - 不合格 → 进入不合格品处置流程
   - 待验 → 进入待验区，等待质量检验结果
5. 签字时记录：签字人、签字时间、验收结论、备注
6. 不允许同一用户签两次（系统校验 user_id 不同）
7. 签字记录不可修改（append-only）
8. 可关联电子药检单（上传附件）

## US-M2-005：智能上架引导

**作为** 保管员
**我要** 在 PDA 上接收系统推荐的上架库位，扫码确认上架
**以便** 商品按温区、色标、货主规则存放到正确位置

### 验收标准

1. 验收合格后，系统自动推荐上架库位，规则：
   - 温区匹配（冷藏商品 → 冷藏库区）
   - 色标匹配（合格品 → 绿色区）
   - 货主匹配（货主专属库位优先）
   - 同品同批就近原则（已有同商品的库位优先）
   - 库位剩余容量足够
2. 保管员可接受推荐或手动选择其他合法库位
3. 手动选择时系统校验温区/色标是否合法（不合法则拒绝）
4. PDA 扫库位码确认上架 → 库存增加
5. 支持整托上架（扫托盘码 = 整托入库位）
6. 支持分箱上架（一个 ASN 的商品分到多个库位）
7. 上架完成后 ASN 状态变为"已完成"
8. 上架操作写入审计追踪 + 库存变动记录
9. **ERP 回传**：上架完成后自动将入库信息（商品/批号/数量/库位/时间）通过 API 回传 ERP（异步，失败可重试）

## US-M2-006：收货异常处理

**作为** 仓库主管
**我要** 处理收货过程中的异常情况（拒收、短少、破损、温度超标）
**以便** 异常有闭环处置记录，满足 GSP 追溯要求

### 验收标准

1. 异常类型：拒收、短少、破损、温度超标、资质异常、其他
2. 拒收：整单或部分拒收，记录拒收原因，通知供应商
3. 短少：实收 < ASN 数量，记录差异，可后续补货
4. 破损：记录破损数量，进入不合格品处置
5. 温度超标：记录超标温度值，可选拒收或标记异常入待验区
6. 所有异常必须有处置结论（处置人、时间、结论）
7. 异常处置写入审计追踪
8. 异常统计可按供应商/商品/类型汇总（报表用）

## US-M2-007：收货单据打印

**作为** 收货员
**我要** 在收货完成后打印验收记录单
**以便** 纸质存档满足 GSP 台账要求

### 验收标准

1. 打印内容：ASN 编号、供应商、到货时间、商品明细（品名/规格/批号/效期/数量）、验收结论、双人签字
2. 冷链商品额外打印：启运温度、到货温度、运输时长
3. 支持蓝牙打印机（PDA 端）和网络打印机（PC 端）
4. 打印记录写入审计追踪（谁打印了什么、什么时间）
5. 使用打印模板引擎（见 US-M2-009）

## US-M2-009：打印模板设计模块

**作为** 系统管理员
**我要** 可视化设计和管理各类打印模板（ASN 单、验收记录、随货同行单、标签等）
**以便** 不同仓库/货主可按需调整打印格式，无需改代码

### 验收标准

1. 模板类型：ASN 单、验收记录单、随货同行单、库位标签、托盘标签、货箱标签、商品标签
2. **可视化模板设计器**：拖拽式布局，支持文本、条码（一维/二维）、表格、图片、动态字段
3. 动态字段绑定：从业务数据中取值（如 `{{asn.code}}`、`{{product.name}}`、`{{batch.expiry_date}}`）
4. 条码/二维码字段：支持绑定 ASN 单号、商品编码、电子监管码、托盘码等
5. 模板版本管理：每次修改保存新版本，可回退
6. 模板与货主关联：不同货主可使用不同模板
7. 模板预览：设计完成后可用样例数据预览打印效果
8. 支持导出为 PDF
9. 打印尺寸配置：A4 / A5 / 热敏标签（自定义宽高）
10. 模板变更写入审计追踪

## US-M2-008：收货进度看板

**作为** 仓库主管
**我要** 在 PC/PAD 端查看今日收货进度（待收/收货中/已完成/异常）
**以便** 实时掌握收货作业状态，及时处理异常

### 验收标准

1. 看板维度：按 ASN 状态分组统计
2. 支持按供应商、商品、时间范围筛选
3. 点击具体 ASN 可查看详情（含验收记录、签字、异常）
4. 异常 ASN 高亮显示
5. 自动刷新（可配置刷新间隔）

## 跨故事约束（适用于所有 M2 用户故事）

1. **审计追踪**：所有操作（签收/验收/上架/异常处置）写入审计表
2. **多货主**：ASN 绑定货主，数据按货主隔离
3. **GSP 强校验**：供应商资质过期 → 拒绝创建 ASN；商品过期 → 拒绝入库
4. **双人验收**：两个不同 user_id 签字，不限角色
5. **冷链**：冷链商品必须录入温度，超标必须有处置记录
6. **PDA 离线**：收货/验收/上架的 PDA 操作支持离线暂存 + 恢复同步
7. **开放 API**：ASN 创建支持外部系统推送（ERP/采购平台）
8. **幂等性**：所有写操作支持 Idempotency-Key，重复提交不产生重复数据
