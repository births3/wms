# 用户故事：H4 企业微信通知与审批模块

> 模块：H4 wechat-work-notify
> 性质：横向能力（所有业务模块共用）
> 波次：Wave 1（与 H1/H2/H3 同期）
> 依赖：H1 权限（需要知道通知接收人）

---

## US-H4-001：通知配置

**作为** 系统管理员
**我要** 配置"什么事件 → 发什么通知 → 给谁"的规则
**以便** 业务事件发生时自动通知相关人员，无需人工传话

### 验收标准

1. 通知事件枚举（可扩展）：
   - 资质到期预警
   - 近效期预警
   - 温度超标
   - ASN 到货
   - 验收不合格
   - 盘点差异
   - 库存预警（安全库存/超储）
   - 审批待办
   - 审批结果
2. 每个事件可配置：
   - 是否启用
   - 通知模板（支持变量占位符）
   - 接收人规则（指定角色 / 指定用户 / 货主相关人）
   - 通知方式：企业微信消息（必选）、短信（可选）、邮件（可选）
3. 配置变更写入审计追踪

---

## US-H4-002：企业微信消息发送

**作为** 系统（自动）
**我要** 在业务事件触发时，按配置规则向企业微信发送通知消息
**以便** 相关人员及时收到提醒

### 验收标准

1. 对接企业微信 API（应用消息 / 群机器人）
2. 消息内容从模板 + 业务数据渲染
3. 发送失败自动重试（可配置重试次数和间隔）
4. 所有发送记录入库（发送时间、接收人、内容、状态：成功/失败/重试中），写入审计追踪
5. 发送记录可查询（按事件/时间/接收人/状态筛选）
6. 支持批量发送（同一事件通知多人）

---

## US-H4-003：企业微信审批流对接

**作为** 系统（自动）
**我要** 将需要审批的业务单据推送到企业微信审批流，审批结果自动回写 WMS
**以便** 审批人在企微上完成审批，WMS 自动流转状态

### 验收标准

1. 支持的审批场景（可扩展）：
   - ASN 作废审批
   - 出库订单作废审批
   - 库存隔离审批
   - 盘点差异审批
   - 质量联系单审批（验收不合格）
   - 货主间货主转换审批
   - 系统配置变更审批（GSP 关键参数）
2. 推送审批单到企微：包含业务摘要、审批人、审批链接
3. 企微审批完成后回调 WMS（webhook / 轮询）
4. 审批结果回写：审批人、审批时间、审批结论（同意/拒绝）、审批意见
5. 审批记录存储在 WMS（不依赖企微历史查询）
6. 审批超时提醒（可配置超时时长）
7. 审批记录写入审计追踪

---

## US-H4-004：通知发送记录查询

**作为** 系统管理员
**我要** 查询所有通知和审批的发送记录
**以便** 排查"通知没收到"或"审批没回写"的问题

### 验收标准

1. 查询维度：事件类型、时间范围、接收人、发送状态
2. 显示字段：事件、时间、接收人、内容摘要、状态、重试次数、失败原因
3. 支持手动重发（失败的通知）
4. 支持导出

---

## 跨故事约束

1. **异步发送**：通知/审批推送不阻塞业务主流程（异步队列）
2. **幂等**：同一事件重复触发不重复发送（去重 key）
3. **多货主**：通知接收人按货主过滤（货主 A 的事件不通知货主 B 的人）
4. **降级**：企微 API 不可用时，通知进入重试队列，不影响业务操作
5. **审计**：所有发送/审批记录 append-only
