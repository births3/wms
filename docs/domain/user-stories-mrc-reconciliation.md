# 用户故事：M-RC 库存对账模块

> 模块：M-RC reconciliation
> 性质：独立业务模块（WMS 与 ERP 库存一致性保障）
> 波次：Wave 3（依赖 M2 入库反馈 + M4 出库反馈都跑通后）
> 依赖：M1 基础档案、M3 库存、H1 权限、H2 审计、H4 企业微信通知

---

## 背景

WMS 入库后反馈 ERP → ERP 记账 → ERP 下出库订单指定批号。
理论上 ERP 库存 = WMS 库存，但可能因网络延迟、并发、人工干预等导致不一致。
对账模块定期比对两边数据，发现差异即推送通知。

---

## US-RC-001：定时对账任务

**作为** 系统（定时任务）
**我要** 按配置的频率自动比对 WMS 库存与 ERP 库存
**以便** 在配置的对账周期内发现数据不一致，防止出库时才暴露问题

### 验收标准

1. 对账频率可配置（默认每天一次，可设为每小时/每 N 小时）
2. 对账维度：按商品+批号+货主，比对 WMS 在库数量 vs ERP 账面数量
3. ERP 库存数据获取方式：调用 ERP API 查询（WMS 主动拉取）
4. 对账结果分类：一致 / WMS 多（WMS > ERP）/ ERP 多（ERP > WMS）
5. 对账结果存储：对账记录表（对账时间、商品、批号、WMS 数量、ERP 数量、差异、状态）
6. 对账任务执行记录写入审计追踪

---

## US-RC-002：差异处理

**作为** 仓库主管
**我要** 查看对账差异明细，并对选择的差异项进行锁定和处理
**以便** 差异不扩大，主管按风险优先级决定哪些差异需要立即冻结

### 验收标准

1. 差异列表：按商品/批号/货主/差异类型筛选
2. **差异不自动锁定**：发现差异后只在差异列表中标记 + 推送企业微信通知（避免误锁影响业务）
3. **主管选择性加锁**：仓库主管在差异列表上勾选要锁定的差异项 → 触发"对账隔离"动作 → 该批次库存状态由"合格"变为"隔离"（携带审批源 = 对账 ID，参见 M3-003）
4. **批量解锁**：差异处理完成后可批量解锁（释放隔离）
5. 处理方式（人工选择）：
   - 以 WMS 实物为准 → 通知 ERP 修正账面
   - 以 ERP 为准 → WMS 做库存调整（走 M-SA 报损/报溢，需审批）
   - 标记为已知差异（如在途、时间差） → 不锁定，列表标记后归档
6. 处理完成后差异状态变为"已处理"
7. 所有锁定/解锁/处理操作写入审计追踪

---

## US-RC-003：手动触发对账

**作为** 仓库主管
**我要** 手动触发一次即时对账（不等定时任务）
**以便** 在怀疑数据不一致时立即确认

### 验收标准

1. 支持全量对账（所有商品）或指定范围（某商品/某批号/某货主）
2. 对账结果与定时对账相同格式
3. 手动触发记录写入审计追踪

---

## US-RC-004：对账报表

**作为** 仓库主管
**我要** 查看对账历史报表（一致率、差异趋势、高频差异商品）
**以便** 分析差异根因，优化流程减少差异

### 验收标准

1. 报表维度：按时间/商品/货主/差异类型
2. 指标：一致率（%）、差异笔数、差异金额（如有）
3. 趋势图：近 30 天一致率变化
4. 高频差异 TOP 10（哪些商品经常不一致）
5. 支持导出 Excel

---

## 跨故事约束

1. **审计追踪**：所有对账操作写入审计表
2. **多货主**：对账按货主隔离
3. **差异锁定 = 主管选择**：差异不自动锁定，由主管在差异列表勾选；锁定动作复用 M3 库存隔离机制（携带审批源=对账 ID）
4. **幂等性**：同一时间窗口重复触发对账不产生重复记录
5. **企业微信通知**：差异发现时通知仓库主管
6. **ERP 接口**：对账依赖 ERP 提供库存查询 API（需确认接口格式）
