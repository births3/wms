## US-M8-001：自动补货算法（门店水位）

**作为** 系统（定时计算）
**我要** 根据门店库存水位和销售预测自动生成配货单
**以便** 门店不断货也不超储

### 验收标准

1. 门店水位：最低库存 / 最高库存（可配置）
2. 销售预测：基于近 N 天销售数据计算日均销量
3. 自动生成配货建议：商品 + 建议数量
4. 配货建议需仓库主管确认后转为出库订单
5. 计算记录写入审计追踪

---

## US-M8-002：越库作业（Cross-Docking）

**作为** 仓库主管
**我要** 将到货商品不入库直接分拨装车配送到门店
**以便** 减少入库-出库环节，加快配送速度

### 验收标准

1. 越库条件：ASN 到货 + 已有对应门店配货单
2. 收货后跳过上架，直接进入分拨（按门店拆分数量）
3. 分拨完成后直接进入发货流程
4. 越库商品不占用库位（不入库存）
5. 越库记录写入审计追踪

---

## 跨故事约束

1. **审计追踪**：所有操作写入审计表
2. **多货主**：连锁门店按货主隔离
3. **业务边界**：经营范围/资质合规校验由 ERP 负责，WMS 不重复
4. **幂等性**：补货建议/越库分拨等写操作支持 Idempotency-Key

### 测试维度覆盖

#### US-M8-001 自动补货算法（门店水位）

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 门店水位配置缺失 → M8_WATERMARK_NOT_CONFIGURED; 仓库库存不足 → 生成部分补货单 + 告警; 算法执行超时 → 重试 + 告警 |
| L5 数据一致 | 补货建议数量 = 目标水位 - 当前库存 - 在途数量; 补货单与库存预占联动 |
| L8 权限 | 系统自动执行; 仓库主管可手动触发/审批; 门店只读 |
| L11 幂等 | 同一门店 + 同一计算周期重复触发 → 返回已有建议（不重复生成） |

#### US-M8-002 越库作业（Cross-Docking）

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 入库商品无匹配出库订单 → 正常入库（不越库）; 越库数量 > 入库数量 → M8_CROSSDOCK_QTY_EXCEEDED; 目标门店不存在 → M8_STORE_NOT_FOUND |
| L5 数据一致 | 越库数量 = 入库直接分配到出库的数量; 不经过上架（库存不增不减，直接流转） |
| L8 权限 | 系统自动匹配; 仓库主管可手动指定越库; 保管员执行 |
| L11 幂等 | 越库分配支持 Idempotency-Key |
