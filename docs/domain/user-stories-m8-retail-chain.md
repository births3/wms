# 用户故事：M8 连锁药店专有

> 模块：M8 retail-chain
> 波次：Wave 5
> 依赖：M1 基础档案、M4 出库、H1 权限

---

## US-M8-001：门店经营范围管控

**作为** 系统（自动校验）
**我要** 在出库时校验门店是否有资质接收该类药品
**以便** 防止向无资质门店配送受限药品（如二类精神药）

### 验收标准

1. 门店经营范围在 M1 客户档案中维护
2. 出库校验规则（M-VR）自动比对：订单商品类别 vs 门店经营范围
3. 不匹配 → 校验异常，阻止出库
4. 校验记录写入审计追踪

---

## US-M8-002：自动补货算法（门店水位）

**作为** 系统（定时计算）
**我要** 根据门店库存水位和销售预测自动生成配货单
**以便** 门店不断货也不超储

### 验收标准

1. 门店水位：最低库存 / 最高库存（可配置）
2. 销售预测：基于近 N 天销售数据计算日均销量
3. 自动生成配货建议：商品 + 建议数量
4. 配货建议需仓库主管确认后转为出库订单
5. 计算记录写入审计追踪

---

## US-M8-003：越库作业（Cross-Docking）

**作为** 仓库主管
**我要** 将到货商品不入库直接分拨装车配送到门店
**以便** 减少入库-出库环节，加快配送速度

### 验收标准

1. 越库条件：ASN 到货 + 已有对应门店配货单
2. 收货后跳过上架，直接进入分拨（按门店拆分数量）
3. 分拨完成后直接进入发货流程
4. 越库商品不占用库位（不入库存）
5. 越库记录写入审计追踪

---

## 跨故事约束

1. **审计追踪**：所有操作写入审计表
2. **多货主**：连锁门店按货主隔离
3. **校验规则**：门店经营范围校验通过 M-VR 规则引擎
