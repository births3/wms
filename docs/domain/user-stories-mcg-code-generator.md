# 用户故事：M-CG 编码生成模块

> 模块：M-CG code-generator
> 性质：横向业务模块（所有单据的编码统一生成）
> 波次：Wave 2（M2 入库 + M4 出库都依赖）
> 依赖：M1 基础档案（货主编码）、H1 权限
> 关联 ADR：ADR-0008 §3 ir.sequence 借鉴；当前用户已确认 WMS 单据号统一采用 no-gap。

---

## 背景

系统中多种单据（ASN、出库订单、盘点单、报损单、报溢单、批号调整单等）都需要唯一编号。编码规则统一管理，避免各模块各自实现导致格式不一致。

---

## US-CG-001：编码规则配置

**作为** 系统管理员
**我要** 配置各类单据的编码生成规则
**以便** 所有单据编号格式统一、可识别、全局唯一

### 验收标准

1. 编码规则组成部分（可组合）：
   - 货主编码（3 位）
   - 业务类型标识（如 ASN、P=入库、R=出库、PD=盘点、SL=报损、SO=报溢、BA=批号调整）
   - 日期（YYYYMMDD 或 YYMMDD，可配置）
   - 流水号（位数可配置，如 4 位/6 位，每日重置或连续递增）
2. 每种单据类型绑定一个编码规则
3. 单据类型：ASN 收货单、出库订单、盘点单、报损单、报溢单、批号调整单（v22）、质量联系单、盲标签
4. 编码规则示例：`HZ001ASNP20260516001` = 货主 HZ001 + ASN + 入库(P) + 日期 + 流水号 001
5. 流水号策略：每日重置 / 连续递增（可配置），所有 WMS 单据号生成均采用 no-gap，不允许回滚后跳号。
6. 编码规则变更写入审计追踪
7. 规则变更不影响已生成的历史编码

---

## US-CG-002：编码生成服务

**作为** 系统（内部调用）
**我要** 在创建单据时调用编码生成服务获取唯一编号
**以便** 各模块无需自己实现编码逻辑，统一调用即可

### 验收标准

1. 提供内部 API：传入（单据类型 + 货主）→ 返回唯一编码
2. **全局唯一**：并发调用不产生重复编码（原子递增）
3. **高性能**：单次生成 < 5ms（不能成为瓶颈）
4. **幂等**：同一请求重复调用返回相同编码（通过请求 ID 去重）
5. 生成记录可查询（按单据类型/日期/货主）
6. 编码生成写入审计追踪
7. no-gap 发号、计数器递增、生成记录和业务单据写入必须支持同一数据库事务；M-CG 不能先独立提交号码再交给业务模块写单据。

---

## 跨故事约束

1. **审计追踪**：规则配置变更 + 编码生成记录写入审计表
2. **多货主**：编码含货主标识，天然隔离
3. **高可用**：编码生成是关键路径，不可单点故障
4. **不可修改**：已生成的编码不可修改或回收

---
5. **幂等性**：编码生成支持 Idempotency-Key（参见 US-CG-002 验收标准 4），同一请求 ID 重复调用返回相同编码
6. **单据类型来源**：`document_type` 仍来自 M1 系统字典，M-CG 不新增自由文本单据类型。

### 测试维度覆盖

#### US-CG-001 编码规则配置

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 规则名重复 → CG_RULE_DUPLICATE; 规则模板语法错误 → CG_TEMPLATE_INVALID; 删除正在使用的规则 → CG_RULE_IN_USE |
| L5 数据一致 | 规则变更后新生成的编码使用新规则; 已生成编码不受影响; 序列号连续不跳号 |
| L8 权限 | 仅系统管理员可配置; 仓库主管只读 |
| L11 幂等 | 配置变更支持 Idempotency-Key |

#### US-CG-002 编码生成服务

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 规则不存在 → CG_RULE_NOT_FOUND; 序列号溢出（达到最大值）→ CG_SEQUENCE_OVERFLOW + 告警; 并发生成冲突 → 自动重试（乐观锁） |
| L5 数据一致 | 生成的编码全局唯一; 序列号严格递增不跳号; 并发安全（不重复） |
| L8 权限 | 各模块创建业务单据时自动调用内部服务; 规则管理和生成记录查询公开 API 必须校验 `mcg.document_numbering.read` / `mcg.document_numbering.write` |
| L11 幂等 | 同一业务请求（Idempotency-Key）重复调用 → 返回首次生成的编码 |

### PDA 弹性

> M-CG 为后端服务，PDA 端不直接操作编码生成。

#### 离线策略

| 场景 | 行为 |
|------|------|
| PDA 离线时需要编码 | 本地预分配编码池（启动时预取 N 个）; 用完提示"需联网获取新编码" |

#### 扫码交互

不适用。

#### 异常恢复

| 场景 | 行为 |
|------|------|
| 预分配编码未使用（APP 崩溃） | 网络恢复后归还未使用编码; 或标记为"已分配未使用"定期清理 |
