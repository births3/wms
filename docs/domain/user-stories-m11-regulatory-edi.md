## 业务边界声明

**"码上放心"和"药监局 EDI"是两类不同的监管接口**：

| 维度 | "码上放心"（追溯码核销）| 药监局 EDI（监管报告）|
|------|---------------------|--------------------|
| 数据来源 | WMS 扫码事件唯一产生 | 多系统汇总（库存在 ERP、温控在外部系统） |
| 实时性 | 高（每次扫码近实时上报） | 低（每日/每周汇总） |
| 触发方式 | 事件驱动（扫码 → 状态变更）| 定时任务（汇总数据推送） |
| **本项目处置** | **WMS 直接对接**（M-TC-007） | **ERP 对接**（WMS 仅反馈数据给 ERP） |
