# 用户故事：M11 监管平台一键对接

> 模块：M11 regulatory-edi
> 波次：Wave 5
> 依赖：M-TC 追溯码、M2 入库、M4 出库、M5 冷链

---

## US-M11-001："码上放心"直连

**作为** 系统（自动）
**我要** 在出入库时自动将追溯码核销信息上传到"码上放心"平台
**以便** 满足药品追溯监管要求

### 验收标准

1. 入库时：追溯码状态上报"已入库"
2. 出库时：追溯码状态上报"已出库" + 流向（客户/门店）
3. 上报方式：调用"码上放心"API（批量异步）
4. 上报失败自动重试 + 企业微信通知
5. 上报记录写入审计追踪
6. 支持手动补报（历史数据补传）

---

## US-M11-002：药监局非现场监管接口

**作为** 系统（定时推送）
**我要** 定时向药监局推送库存流向数据
**以便** 满足"非现场监管"要求

### 验收标准

1. 推送内容：库存快照、出入库流向、温控数据
2. 推送频率可配置（默认每日）
3. 数据格式按药监局接口规范
4. 推送失败自动重试 + 企业微信通知
5. 推送记录写入审计追踪

---

## US-M11-003：监管对接配置与监控

**作为** 系统管理员
**我要** 配置监管平台的对接参数并监控对接状态
**以便** 确保数据持续上报不中断

### 验收标准

1. 平台配置：API 地址、认证信息、推送频率、重试策略
2. 对接状态看板：最近上报时间、成功率、失败记录
3. 失败记录可手动重试
4. 配置变更写入审计追踪

---

## 跨故事约束

1. **审计追踪**：所有上报操作写入审计表
2. **追溯码**：依赖 M-TC 追溯码模块的码库数据
3. **外部依赖**：需要"码上放心"接入资质 + 药监局接口权限（Wave 1 启动时并行申请）
4. **降级**：监管接口不可用时不阻塞业务，数据暂存后补报
