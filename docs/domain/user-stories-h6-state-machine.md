# 用户故事：H6 状态机引擎

> 模块：H6 state-machine
> 性质：横向技术能力
> 波次：Wave 1 基础能力；业务状态执行在后续业务模块接入时扩展
> 依赖：H1 权限、H2 审计追踪、H3 OpenAPI 契约
> 关联规格：[基础设施模块技术规格](../infra/technical-specs.md)

## US-H6-001：状态机定义注册与转换校验

**作为** 业务模块开发者
**我要** 查询系统内已注册的状态机定义，并校验某个状态转换是否被允许
**以便** M2、M4、M-TE 等模块在接入统一状态执行前，先复用同一套状态图和转换规则

### 验收标准

1. 提供状态机定义列表接口，返回状态机编码、名称、业务模块、版本、状态集合和转换集合。
2. 提供单个状态机定义查询接口；状态机不存在时返回明确错误码。
3. 提供状态转换校验接口，输入 `from_state`、`to_state` 和可选 `event_code`，返回 `allowed` 与拒绝原因。
4. 首批注册 `asn`、`outbound_order`、`warehouse_task` 三类状态机。
5. 每个状态机必须包含唯一初始态、至少一个终态，并显式列出允许的转换事件。
6. 状态机定义运行时不可修改；新增或修改状态图必须通过代码和 OpenAPI 契约变更。
7. 接口需要 H1 权限 `h6.state_machine.read`，并通过数据库迁移登记权限、授予内置 `system_admin` 角色。
8. 本故事只覆盖定义注册和转换校验；真正执行状态转换、事务原子性、事件发布和 H2 审计写入在业务模块接入状态机执行能力时补充。

### 测试维度覆盖

| 维度 | 场景 |
|------|------|
| L1 单元 | 状态机定义包含初始态、终态和允许转换；非法转换返回 `allowed=false` |
| L2 API | OpenAPI 包含定义列表、定义详情、转换校验三个接口 |
| L3 流程 | API 消费方能连续读取 M2 ASN、M4 出库单、M-TE 任务三类状态图；业务状态写入接入另开执行切片 |
| L4 错误路径 | 未知状态机返回 404；未知状态或非法跳转返回拒绝原因 |
| L8 权限 | 未具备 `h6.state_machine.read` 权限时拒绝访问 |
| 契约一致性 | OpenAPI 和 TypeScript API schema 同步生成；首个正式版本前不建立兼容基线 |

### 跨故事约束

1. H6 不替代 M2/M4/M-TE 的业务字段；业务表继续保存自身状态字段。
2. H6 不在本故事提供运行时可编辑配置，避免生产状态图被无审计修改。
3. 后续状态转换执行能力必须在同一事务内完成业务状态写入、H2 审计和领域事件发布。
4. 本故事接口均为只读或只读校验，不要求 `Idempotency-Key`；后续状态转换执行属于写操作，必须补 L11 幂等性测试。
5. 本故事不声称 M2、M4、M-TE 已切换运行时状态写入逻辑；当前证据只证明三类定义可由同一 H6 API 读取和校验。
