# 用户故事：M-QL 质量联系单模块

> 模块：M-QL quality-liaison
> 性质：独立业务模块（校验异常/验收不合格/强制通过等场景触发）
> 波次：Wave 2（M-VR 校验规则模块依赖）
> 依赖：H1 权限、H2 审计、H4 企业微信

---

## 背景

当业务流程中出现质量/合规相关的异常（校验不通过需强制、验收不合格、养护异常等），需要生成质量联系单走审批流程。不同类型的质量联系单走不同的企业微信审批模板，审批结果回写系统后才能继续操作。

---

## US-QL-001：质量联系单类型与审批模板配置

**作为** 系统管理员
**我要** 配置质量联系单的类型，并为每种类型绑定企业微信审批模板
**以便** 不同场景的质量问题走不同的审批流程

### 验收标准

1. 质量联系单类型（可扩展）：
   - 校验强制通过（入库/出库校验异常需强制放行）
   - 验收不合格（入库验收发现质量问题）
   - 养护异常（在库养护发现质量问题）
   - 库存状态调整（合格→隔离/不合格）
   - 近效期处置（近效期商品处置决策）
   - 其他（自定义类型）
2. 每种类型绑定一个企业微信审批模板（模板 ID）
3. 每种类型可配置：审批人规则（指定角色/指定人/按货主）、超时时长
4. 类型可启用/停用
5. 配置变更写入审计追踪

---

## US-QL-002：创建质量联系单

**作为** 系统（自动）/ 仓库主管
**我要** 在异常场景触发时自动或手动创建质量联系单
**以便** 启动审批流程，记录质量问题的处置过程

### 验收标准

1. **自动创建**触发场景：
   - M-VR 校验异常选择"强制通过" → 自动创建"校验强制通过"类型联系单
   - M2 验收不合格 → 自动创建"验收不合格"类型联系单
   - M3 养护异常 → 自动创建"养护异常"类型联系单
   - M3 库存状态调整 → 自动创建"库存状态调整"类型联系单
2. **手动创建**：仓库主管可在界面手动创建任意类型的质量联系单
3. 联系单必填：类型、关联单据（ASN 号/订单号/批号）、问题描述、处置建议
4. 联系单状态：待审批 → 审批中 → 已通过 / 已拒绝
5. 创建后自动推送到企业微信审批流（按类型选择对应审批模板）
6. 创建记录写入审计追踪

---

## US-QL-003：质量联系单审批

**作为** 审批人（通过企业微信）
**我要** 在企业微信上审批质量联系单（同意/拒绝 + 审批意见）
**以便** 质量问题有明确的处置决策

### 验收标准

1. 审批人在企业微信收到审批通知（含问题摘要、关联单据、处置建议）
2. 审批动作：同意 / 拒绝 + 必填审批意见
3. 审批结果自动回写 WMS：
   - **同意** → 联系单状态变"已通过" → 触发后续动作（如：强制通过校验、确认不合格品处置方式）
   - **拒绝** → 联系单状态变"已拒绝" → 原操作不执行（如：不允许强制通过，订单保持校验异常）
4. 审批超时提醒（按类型配置的超时时长）
5. 审批记录存储在 WMS（审批人、时间、结论、意见）
6. 审批记录写入审计追踪

---

## US-QL-004：质量联系单与业务流程联动

**作为** 系统（自动）
**我要** 在质量联系单审批通过后自动执行对应的业务动作
**以便** 审批结果直接驱动业务流转，无需人工二次操作

### 验收标准

1. **校验强制通过**审批通过 → 订单状态从"校验异常"变为"已确认"/"待收货" + 标记"合规风险"
2. **验收不合格**审批通过 → 确认处置方式（报损/采退/降级）→ 执行对应操作
3. **养护异常**审批通过 → 确认处置方式（移库到不合格区/报损/继续观察）
4. **库存状态调整**审批通过 → 执行状态变更（加减锁）+ 反馈 ERP
5. 审批拒绝 → 原操作不执行，订单/库存保持当前状态
6. 联动执行写入审计追踪

---

## US-QL-005：质量联系单查询与统计

**作为** 仓库主管
**我要** 查询质量联系单历史记录和统计报表
**以便** 分析质量问题趋势，改进供应商管理和仓库操作

### 验收标准

1. 查询维度：类型、状态、时间范围、关联商品/供应商/货主
2. 统计报表：
   - 按类型分布（哪种质量问题最多）
   - 按供应商分布（哪个供应商问题最多）
   - 按时间趋势（月度质量联系单数量变化）
   - **合规风险统计**：强制通过的笔数、原因分布
3. 支持导出 Excel
4. 联系单详情可查看完整审批链路

---

## 跨故事约束

1. **审计追踪**：所有创建/审批/联动操作写入审计表
2. **多货主**：质量联系单按货主隔离
3. **企业微信审批**：所有审批通过企业微信完成，结果回写 WMS
4. **不阻塞但必须走流程**：强制通过不是"跳过"，而是"走质量联系单审批后放行"
5. **合规风险标记**：强制通过审批的订单永久标记"合规风险"
6. **可追溯**：每张质量联系单关联到具体单据（ASN/订单/批号），可正反向追溯
