# 用户故事：M-PK 包装站

> 模块：M-PK packing-station
> 性质：独立业务模块（出库复核后的装箱/称重/贴面单环节）
> 波次：Wave 4（依赖 M4 出库复核完成 + M-TE 任务引擎 + H5 快递）
> 依赖：M4 出库、M-TE 任务引擎、M-TC 追溯码、H5 快递、M1 商品（重量/体积）

---

## 背景

拣选复核完成后，商品进入包装站进行装箱、称重校验、追溯码核验、贴快递面单。支持多品合箱和保温箱配置。

---

## US-PK-001：包装站工位管理

**作为** 系统管理员
**我要** 配置包装站工位（工位编号、绑定设备、适用温区）
**以便** 系统知道有多少包装工位可用，合理分配任务

### 验收标准

1. 工位属性：编号、名称、绑定打印机、绑定电子秤、适用温区（常温/冷链）
2. 工位状态：空闲/忙碌/停用
3. 保管员登录工位（PDA/PC 扫工位码）→ 工位变忙碌
4. 工位配置变更写入审计追踪

---

## US-PK-002：装箱作业

**作为** 保管员（包装岗）
**我要** 在包装站将拣选完成的商品装入出库箱
**以便** 商品安全包装后可以发货

### 验收标准

1. 包装任务来源：拣选复核完成后，任务引擎生成"装箱"任务分配到包装站
2. 扫描订单号/波次号 → 显示待装箱商品明细
3. **装箱操作**：扫商品码/追溯码 → 确认装入哪个出库箱
4. **多品合箱**：多个订单的商品可装入同一个出库箱（系统建议合箱方案）
5. **出库箱选择**：系统根据商品总体积/总重量建议箱型（大/中/小）
6. 装箱完成后扫出库箱码封箱确认
7. 装箱记录写入审计追踪

---

## US-PK-003：称重校验

**作为** 保管员（包装岗）
**我要** 在封箱后对出库箱称重，系统自动校验重量是否合理
**以便** 发现漏装/多装/错装

### 验收标准

1. 电子秤自动读取重量（对接电子秤设备）
2. 系统计算理论重量 = 箱内所有商品重量之和 + 包材重量
3. **校验规则**：实际重量与理论重量的偏差 < 可配置阈值（默认 ±5%）
4. 偏差超标 → 报警提示（可能漏装/多装）→ 需人工确认
5. 人工确认后可强制通过（记录原因）
6. 称重记录写入审计追踪

---

## US-PK-004：保温箱配置（冷链）

**作为** 系统（自动建议）/ 保管员
**我要** 根据商品温区和当前气温，建议保温箱型号和蓄冷剂（冰袋）配置
**以便** 冷链商品在运输途中保持温度合规

### 验收标准

1. 触发条件：出库箱内含冷链商品
2. 系统建议：
   - 保温箱型号（根据体积）
   - 蓄冷剂数量（根据运输时长 × 当前气温 × 商品温区要求）
3. 配置规则可维护（气温区间 → 蓄冷剂数量映射表）
4. 保管员确认或调整建议
5. 保温箱配置记录写入审计追踪（GSP 冷链记录）

---

## US-PK-005：追溯码出库核验

**作为** 保管员（包装岗）
**我要** 在装箱时扫追溯码核验商品身份和数量
**以便** 确保出库商品与订单一致，满足追溯要求

### 验收标准

1. 装箱时扫追溯码 → 系统从码库查询：商品/批号/效期/数量
2. 自动比对订单明细：品种、批号、数量
3. 不匹配报警（扫错品/扫错批）
4. 扫码完成后追溯码状态变为"已出库"
5. 支持大码扫码（自动展开为中/小码数量）
6. 核验记录写入审计追踪

---

## US-PK-006：快递面单打印

**作为** 保管员（包装岗）
**我要** 在装箱完成后打印快递面单并贴到出库箱上
**以便** 包裹可以交接给快递

### 验收标准

1. 装箱 + 称重 + 追溯码核验全部完成后可打印
2. 系统按 H5 快递选择规则自动推荐快递商
3. 调用快递 API 获取运单号 → 打印面单
4. 面单贴到出库箱 → 扫面单条码确认关联
5. 一个出库箱一张面单
6. 打印记录写入审计追踪

---

## 跨故事约束

1. **审计追踪**：所有包装操作写入审计表
2. **任务引擎**：包装任务通过 M-TE 分配到工位
3. **追溯码**：装箱时必须扫码核验（复用 M-TC 模块）
4. **快递**：面单打印复用 H5 快递模块
5. **称重设备**：需对接电子秤硬件（串口/USB/网络）
6. **打印模板**：面单使用 US-M2-009 打印模板引擎
7. **冷链 GSP**：保温箱配置记录是 GSP 合规证据
8. **多货主**：包装按货主隔离（不同货主的商品不混箱）
