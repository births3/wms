# 用户故事：H9 打印模板引擎

> 模块：H9 print-template
> 性质：横向技术能力
> 波次：Wave 4-5 首批接入，后续随打印场景扩展
> 依赖：H1 权限与多租户、H2 审计追踪、H3 OpenAPI 契约、M1 系统字典、H5 快递
> 关联 ADR：[ADR-0036 打印模板引擎](../adr/0036-print-template-engine.md)

---

## 背景

打印模板原先内嵌在 M2 的 US-M2-009 中，但实际被 M2、M4、H5、M6、M-PK、M1 标签等多个模块复用。继续放在 M2 会导致模板类型、字段库、版本、货主覆盖、审计和打印失败策略分散实现。

H9 作为横向打印模板引擎，统一管理模板类型、字段库、字段元数据、模板版本、业务接入和打印记录。第一阶段使用 hiprint WebComponent 承载可视化设计器，PC Web 先支持浏览器预览和浏览器打印；静默客户端、后端 PDF/Word 渲染、电子签章深度能力作为后续接入边界。

---

## 首批范围

1. M2：ASN 单、验收记录单。
2. M4：随货同行单。
3. M1/M3/M-PK：库位标签、LPN 标签、商品标签。
4. H5：快递面单保留 H9 模板接口，设备失败处理仍以 H5 通用打印策略为准。
5. M6：台账打印保留 H9 模板接口，法定报表导出继续遵守 ADR-0023。

## US-H9-001：打印模板类型字典

**作为** 系统管理员
**我要** 在系统字典维护打印模板类型
**以便** 不同业务单据按类型选择模板和字段库

### 验收标准

1. 系统字典新增 `print_template_type` 分类，不替代 M1 的 `document_type` 单据类型字典。
2. 字典项字段至少包含：编码、名称、字段库编码、业务模块、业务方向、纸张类型、默认作用域、启用状态、排序号。
3. 首批预置类型包含：ASN 单、验收记录单、随货同行单、库位标签、LPN 标签、商品标签。
4. 每个启用的模板类型必须绑定一个字段库编码，未绑定时禁止保存启用状态。
5. 支持全局默认和货主覆盖；货主配置优先级高于全局配置。
6. 字典项创建、修改、停用写入 H2 审计追踪。

---

## US-H9-002：字段库生成与字段元数据维护

**作为** 业务模块开发者
**我要** 基于 OpenAPI schema 生成打印字段库，并在数据库维护字段元数据
**以便** 模板设计器只能使用受控字段

### 验收标准

1. 字段库草稿从 H3 OpenAPI schema 生成，记录字段路径、字段类型、来源 schema、业务模块和字段库编码。
2. 数据库字段元数据至少维护：显示名称、字段分组、说明、示例值、是否可打印、是否敏感、脱敏规则、格式化规则、是否支持条码、是否支持二维码、是否表格明细字段、排序号。
3. 字段库支持草稿和发布两个状态；只有已发布字段库版本可被模板版本绑定。
4. 已发布字段库版本不可改写；字段变更必须生成新版本，并写入 H2 审计追踪。
5. 发布前校验字段路径仍存在于当前 OpenAPI schema；不存在时返回 `H9_FIELD_PATH_INVALID`。

---

## US-H9-003：模板设计与版本管理

**作为** 系统管理员
**我要** 使用可视化设计器维护模板并发布版本
**以便** 模板变更可追溯且不影响历史打印

### 验收标准

1. 第一阶段使用 hiprint WebComponent 作为模板设计器，WMS 负责外围业务 UI、权限、字段库、版本和审计。
2. 模板主数据至少包含：模板编码、模板名称、模板类型编码、作用域、货主、启用状态、默认标记、备注。
3. 保存模板时存储 hiprint JSON、字段绑定清单、纸张参数、设计器版本和模板版本号。
4. 模板版本保存时绑定当前已发布字段库版本；字段库后续升级不自动改写旧模板版本。
5. 修改已发布模板时生成新草稿版本；发布后才成为新的可用版本。
6. 已产生打印记录的模板版本禁止物理删除，只允许停用模板主数据，并写入 H2 审计追踪。

---

## US-H9-004：预览与浏览器打印

**作为** 仓库主管/收货员/保管员
**我要** 根据业务单据预览并打印单据或标签
**以便** 现场作业和纸质留存使用同一套模板规则

### 验收标准

1. 第一阶段 PC Web 使用浏览器预览和浏览器打印，不默认引入静默打印客户端。
2. 预览数据由业务接口和字段库共同提供；必填字段缺失时返回 `H9_TEMPLATE_FIELD_MISSING`。
3. 执行打印时写入打印记录，记录模板版本、业务单据标识、货主、操作人、打印状态、失败原因和重试次数。
4. 补打同一业务单据时复用原业务数据，不重新生成业务单号。
5. 打印机离线、蓝牙断开、待补打队列等设备侧失败处理参照 H5 通用打印策略。

---

## US-H9-005：业务模块接入规则

**作为** 业务模块开发者
**我要** 通过 H9 解析模板并执行打印
**以便** 各模块不重复实现模板选择、字段校验和打印记录

### 验收标准

1. 模板解析顺序为：显式传入模板并校验可用 → 货主默认模板 → 全局默认模板；禁止跨货主回退。
2. H9 首批接入 M2 ASN 单、M2 验收记录单、M4 随货同行单、库位标签、LPN 标签、商品标签。
3. H5 快递面单、M6 法定台账、后端 PDF/Word 渲染和静默打印客户端只接入 H9 契约，不在第一阶段展开深度实现。
4. 业务接入必须处理 `H9_TEMPLATE_NOT_FOUND`、`H9_TEMPLATE_DISABLED`、`H9_FIELD_LIBRARY_NOT_PUBLISHED`、`H9_TEMPLATE_FIELD_MISMATCH`。
5. 权限码至少包含 `h9.print_template.read`、`h9.print_template.write`、`h9.print_template.publish`、`h9.print_template.print`。
6. 接入新增打印场景时，必须补 L2 API 契约测试和 L3 业务流程测试。

## 跨故事约束

1. **权限与多货主**：所有模板、字段库元数据和打印记录必须按 H1 鉴权；货主级模板只能被对应货主使用。
2. **审计追踪**：模板类型、字段元数据、字段库发布、模板发布、模板停用、打印动作都写入 H2 审计追踪。
3. **OpenAPI 单一事实源**：字段库草稿来自 H3 OpenAPI schema；数据库元数据只补充展示、格式化、敏感性和打印能力，不发明业务字段。
4. **版本不可改写**：已发布字段库版本、已发布模板版本、已产生打印记录的版本不可改写。
5. **打印失败策略**：设备连接、重试、待补打队列按 H5 通用打印策略执行；H9 只记录模板解析和打印动作结果。
6. **M6 边界**：H9 提供模板能力，M6 法定报表的数据口径、PDF 留痕和签章边界仍遵守 ADR-0023。
7. **幂等性**：模板创建、模板发布、字段库发布和打印动作必须支持 Idempotency-Key 或等价业务幂等键。
8. **敏感字段**：字段元数据标记为敏感时，预览、打印、导出必须按脱敏规则处理。
9. **依赖治理**：引入 hiprint 相关依赖前，按治理规则确认许可证、维护活跃度、漏洞风险和浏览器兼容性。

### 测试维度覆盖

#### US-H9-001 打印模板类型字典

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 模板类型编码重复 → H9_TEMPLATE_TYPE_DUPLICATE; 启用时未绑定字段库 → H9_FIELD_LIBRARY_REQUIRED |
| L5 数据一致 | 货主覆盖优先于全局默认; 停用类型后禁止新增模板 |
| L8 权限 | 仅系统管理员可维护; 仓库主管只读 |
| L11 幂等 | 重复创建同一编码返回首次结果或明确重复错误 |

#### US-H9-002 字段库生成与字段元数据维护

| 维度 | 场景 |
|------|------|
| L4 错误路径 | OpenAPI 字段路径不存在 → H9_FIELD_PATH_INVALID; 元数据格式规则不合法 → H9_FIELD_FORMAT_INVALID |
| L5 数据一致 | 发布版本与字段元数据同事务写入; 已发布版本不可改写 |
| L8 权限 | 仅系统管理员和授权开发者可维护字段元数据 |
| L11 幂等 | 重复发布同一草稿版本返回同一发布版本 |

#### US-H9-003 模板设计与版本管理

| 维度 | 场景 |
|------|------|
| L4 错误路径 | hiprint JSON 不合法 → H9_TEMPLATE_JSON_INVALID; 模板编码重复 → H9_TEMPLATE_DUPLICATE; 字段绑定不存在 → H9_TEMPLATE_FIELD_MISMATCH |
| L5 数据一致 | 模板版本绑定字段库版本; 发布新版本不影响旧打印记录 |
| L8 权限 | 仅系统管理员可发布; 仓库主管可预览 |
| L11 幂等 | 同一模板保存请求重复提交返回同一草稿版本 |

#### US-H9-004 预览与浏览器打印

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 模板不存在 → H9_TEMPLATE_NOT_FOUND; 必填字段缺失 → H9_TEMPLATE_FIELD_MISSING; 浏览器打印取消 → 记录取消状态 |
| L5 数据一致 | 打印记录引用模板版本和业务单据; 补打不重新生成业务单号 |
| L8 权限 | 具备对应业务打印权限才可打印; 跨货主 → 403 |
| L11 幂等 | 同一业务单据重复打印不重复生成业务数据 |

#### US-H9-005 业务模块接入规则

| 维度 | 场景 |
|------|------|
| L2 API 契约 | 模板解析、预览、打印接口返回统一错误码和字段结构 |
| L3 业务流程 | M2 ASN 单、M2 验收记录单、M4 随货同行单、标签打印走同一解析顺序 |
| L4 错误路径 | 货主模板不存在时回退全局默认; 全局也不存在 → H9_TEMPLATE_NOT_FOUND |
| L5 数据一致 | 业务单据数据、模板版本和打印记录同源可追溯 |
| L8 权限 | 打印权限由业务权限和 H9 权限共同校验 |
| L11 幂等 | 业务打印接口重复调用不重复生成业务单号 |
