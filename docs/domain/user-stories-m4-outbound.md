# 用户故事：M4 销售出库作业

> 模块：M4 outbound
> 依赖：M1 基础档案、M3 库存、H1 权限、H2 审计
> 关联 ADR：0001、0006（TDD）

---

## US-M4-001：出库订单管理

**作为** 仓库主管（或外部系统通过 API）
**我要** 创建和管理出库订单（销售出库/调拨出库/退货出库）
**以便** 驱动后续拣选、复核、发货流程

### 验收标准

1. 订单类型：销售出库、调拨出库、退货出库
2. 订单必填：客户/门店、商品明细（商品+**批号**+数量，批号由 ERP 指定）、要求交货日期
3. 订单状态：草稿 → 已确认 → 拣选中 → 已复核 → 已发货 → 已签收
4. **订单作废**：状态为"草稿"或"已确认"（未进入波次/拣选）时可申请作废，需仓库主管审批；拣选中及之后不可作废
5. **库存校验**（非分配）：确认订单时校验 ERP 指定的批号在 WMS 有足够库存
   - 只校验"合格"状态库存
   - 门店经营范围校验：受限药品不可配送到无资质门店
   - 校验不通过 → 反馈 ERP "库存不足"
6. **开放 API**：支持外部系统推送出库订单（ERP 推送，含商品+批号+数量）
7. 订单创建/修改/作废写入审计追踪

## US-M4-002：波次规划

**作为** 仓库主管
**我要** 将多个出库订单合并为一个波次，由波次算法决定从哪些库位拣选并优化路径
**以便** 提高拣选效率（合并同库区/同路径的拣选动作，减少行走距离）

### 验收标准

1. 波次创建方式：
   - 手动选择订单组成波次
   - 自动波次：按规则（同客户/同库区/同配送路线/同时间窗）自动合并
2. **波次算法（WMS 核心价值）**：
   - 输入：订单明细（商品+批号+数量，批号由 ERP 指定）
   - 决策：从哪些库位拣（同商品同批号可能分布在多个库位）
   - 优化：拣选路径最短（按库位物理位置排序）
   - 约束：只从"合格"状态库位拣
3. 波次状态：待下发 → 拣选中 → 已完成
4. 波次下发后生成拣选任务（含具体库位+数量，按路径排序）
5. 一个订单只能属于一个波次
6. 波次可取消（未开始拣选时）
7. 波次完成后自动流转到复核环节
8. 波次创建/取消写入审计追踪

## US-M4-003：PDA 拣选作业

**作为** 保管员
**我要** 在 PDA 上按拣选任务指引，到指定库位扫码拣货
**以便** 准确高效地完成拣选，避免拣错

### 验收标准

1. PDA 显示拣选任务列表（按波次/优先级排序）
2. 任务详情：目标库位（排-列-层）→ 商品 → 批号 → 数量
3. **最优路径引导**：按库位物理位置排序，减少行走距离
4. 拣选操作：扫库位码 → 扫商品码/电子监管码 → 确认数量
5. **批次强校验**：扫码后系统校验批号是否与分配一致，不一致则报警拒绝
6. 支持整托拣选（扫托盘码 = 拣整托）
7. 支持整箱拣选（扫货箱码 = 拣整箱）
8. 拣选短少处理：实际可拣 < 分配数量时，记录短少原因，触发补拣或缺货
9. 拣选完成后任务状态变为"已拣选"
10. **离线支持**：断网时暂存拣选数据
11. 拣选操作写入审计追踪

## US-M4-004：出库复核

**作为** 保管员（复核岗）
**我要** 对拣选完成的商品进行逐件复核，确认品种和数量正确
**以便** 防止拣错/拣少，满足 GSP 出库复核要求

### 验收标准

1. **双人复核**：拣选人和复核人必须是不同用户（系统校验 user_id 不同）
2. 复核方式：PDA 扫码逐件核对 或 PC 端扫码枪核对
3. 扫码校验：商品码/电子监管码 → 系统比对订单明细
4. 数量校验：复核数量必须 = 订单分配数量（多/少都报警）
5. 复核通过 → 订单状态变为"已复核"
6. 复核不通过 → 退回拣选（记录原因）
7. 复核记录写入审计追踪（复核人、时间、结论）

## US-M4-005：随货同行单打印

**作为** 保管员（复核岗）
**我要** 在复核通过后打印随货同行单
**以便** 随货附带合规单据，满足 GSP 要求

### 验收标准

1. 随货同行单内容：销售方信息、购货方信息、商品明细（品名/规格/批号/效期/数量/单位）、发货日期、质量状态
2. **多货主抬头**：3PL 模式下，随货同行单抬头为货主信息（非仓库方）
3. 使用打印模板引擎（US-M2-009）
4. 支持一单多页（商品明细超一页时自动分页）
5. 打印后订单状态可流转到"已发货"
6. 打印记录写入审计追踪

---

## US-M4-006：发货与交接

**作为** 保管员
**我要** 将复核通过的包裹交接给司机/快递，记录交接信息
**以便** 明确责任交接节点，后续可追溯

### 验收标准

1. 交接记录：司机/快递员姓名、车牌号、交接时间、包裹数量
2. 冷链商品额外记录：装车温度、保温箱/冰袋配置
3. 交接后订单状态变为"已发货"
4. 支持批量交接（同一司机多个订单一次交接）
5. 交接单可打印（含交接双方签字栏）
6. 交接记录写入审计追踪

---

## US-M4-007：出库进度看板

**作为** 仓库主管
**我要** 在 PC/PAD 端查看出库作业进度（待分配/拣选中/待复核/已发货）
**以便** 实时掌握出库状态，及时处理瓶颈和异常

### 验收标准

1. 看板维度：按订单状态分组统计
2. 支持按客户、商品、波次、时间范围筛选
3. 异常高亮：超时未拣选、复核不通过、缺货
4. 点击具体订单可查看详情（含拣选记录、复核记录）
5. 自动刷新（可配置间隔）
6. 支持导出当日出库汇总
7. 看板为只读查询，不产生写操作，无需独立审计追踪（数据来源的写操作已各自审计）

---

## US-M4-008：出库退货处理

**作为** 仓库主管
**我要** 处理客户退货（退货入库），将退回商品重新纳入库存管理
**以便** 退货有完整记录，退回商品按质量状态正确归位

### 验收标准

1. 退货单必填：原出库订单号、客户、退货商品明细（商品+批号+数量+退货原因）
2. 退货入库时验收：外观/包装/效期检查
3. 验收结论决定库存状态：
   - 合格 → 合格（回到可用库存）
   - 不合格 → 不合格品区
   - 需复验 → 隔离区
4. 退货入库写入审计追踪
5. 退货统计可按客户/商品/原因汇总

## 跨故事约束（适用于所有 M4 用户故事）

1. **审计追踪**：所有出库操作（分配/拣选/复核/发货/退货）写入审计表
2. **多货主**：订单绑定货主，数据按货主隔离；随货同行单用货主抬头
3. **出库批号由 ERP 指定**：WMS 只校验库存并决定从哪个库位拣（波次算法）
4. **双人复核**：拣选人 ≠ 复核人（系统校验）
5. **库存校验**：ERP 指定批号在 WMS 无库存时反馈 ERP
6. **门店经营范围校验**：受限药品不可配送到无资质门店
7. **PDA 离线**：拣选支持离线暂存
8. **幂等性**：所有写操作支持 Idempotency-Key
9. **开放 API**：订单创建、订单状态查询支持外部系统调用
10. **打印模板**：随货同行单、交接单使用 US-M2-009 打印模板引擎
