# 用户故事：M9 3PL 计费管理

> 模块：M9 billing
> 波次：Wave 5
> 依赖：M1 基础档案（货主/合同）、M2 入库、M3 库存、M4 出库

---

## US-M9-001：计费规则配置

**作为** 系统管理员
**我要** 按货主/合同配置计费规则（仓储费/作业费/耗材费）
**以便** 系统自动计算费用

### 验收标准

1. 计费项：仓储费（按面积或托盘位）、入库作业费、出库作业费、耗材费、装卸费
2. 每项可配置：单价、计量单位、计费周期、阶梯价格
3. 按货主/合同绑定不同费率
4. 规则变更写入审计追踪

---

## US-M9-002：自动计费

**作为** 系统（定时/事件触发）
**我要** 根据实际业务数据自动计算各货主的费用
**以便** 月结时直接出账单

### 验收标准

1. 仓储费：按日计算（库存占用面积/托盘位 × 单价）
2. 作业费：按实际操作次数计算（入库笔数/出库笔数/拣选行数）
3. 耗材费：按实际使用量计算（出库箱/保温箱/冰袋）
4. 计费数据来源：M2 入库记录、M4 出库记录、M3 库存快照
5. 计费明细可穿透查询（每笔费用对应哪个单据）
6. 计费记录写入审计追踪

---

## US-M9-003：账单管理

**作为** 仓库主管 / 货主
**我要** 查看和管理月结账单
**以便** 货主确认费用、财务对账

### 验收标准

1. 月结账单自动生成（每月 1 号生成上月账单）
2. 账单内容：货主、计费周期、各项费用明细、合计
3. 账单状态：待确认 → 已确认 → 已结算
4. 货主可在线查看账单明细
5. 支持导出 Excel/PDF
6. 账单变更写入审计追踪

---

## 跨故事约束

1. **审计追踪**：计费规则/计算/账单全链路审计
2. **多货主**：按货主独立计费和出账
3. **数据来源**：计费数据来自各业务模块的实际操作记录（不可手工篡改）
4. **幂等性**：计费计算/账单生成支持 Idempotency-Key，同一计费周期重复触发不重复出账
