# 用户故事：M9 3PL 计费管理

> 模块：M9 billing
> 波次：Wave 5
> 依赖：M1 基础档案（货主/合同）、M2 入库、M3 库存、M4 出库

---

## US-M9-001：计费规则配置

**作为** 系统管理员
**我要** 按货主/合同配置计费规则（仓储费/作业费/耗材费）
**以便** 系统自动计算费用

### 验收标准

1. 计费项：仓储费（按面积或托盘位）、入库作业费、出库作业费、耗材费、装卸费
2. 每项可配置：单价、计量单位、计费周期、阶梯价格
3. 按货主/合同绑定不同费率
4. 规则变更写入审计追踪

---

## US-M9-002：自动计费

**作为** 系统（定时/事件触发）
**我要** 根据实际业务数据自动计算各货主的费用
**以便** 月结时直接出账单

### 验收标准

1. 仓储费：按日计算（库存占用面积/托盘位 × 单价）
2. 作业费：按实际操作次数计算（入库笔数/出库笔数/拣选行数）
3. 耗材费：按实际使用量计算（出库箱/保温箱/冰袋）
4. 计费数据来源：M2 入库记录、M4 出库记录、M3 库存快照
5. 计费明细可穿透查询（每笔费用对应哪个单据）
6. 计费记录写入审计追踪

---

## US-M9-003：账单管理

**作为** 仓库主管 / 货主
**我要** 查看和管理月结账单
**以便** 货主确认费用、财务对账

### 验收标准

1. 月结账单自动生成（每月 1 号生成上月账单）
2. 账单内容：货主、计费周期、各项费用明细、合计
3. 账单状态：待确认 → 已确认 → 已结算
4. 货主可在线查看账单明细
5. 支持导出 Excel/PDF
6. 账单变更写入审计追踪

---

## 跨故事约束

1. **审计追踪**：计费规则/计算/账单全链路审计
2. **多货主**：按货主独立计费和出账
3. **数据来源**：计费数据来自各业务模块的实际操作记录（不可手工篡改）
4. **幂等性**：计费计算/账单生成支持 Idempotency-Key，同一计费周期重复触发不重复出账

### 测试维度覆盖

#### US-M9-001 计费规则配置

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 规则公式语法错误 → M9_FORMULA_INVALID; 费率 < 0 → M9_INVALID_RATE; 规则生效日期冲突 → M9_RULE_CONFLICT |
| L5 数据一致 | 规则变更后新计费使用新规则; 已出账单不受影响 |
| L8 权限 | 仅系统管理员可配置; 货主只读本货主规则 |
| L11 幂等 | 配置变更支持 Idempotency-Key |

#### US-M9-002 自动计费

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 无匹配计费规则 → M9_NO_RULE_MATCH + 告警; 计算溢出（金额超大）→ M9_AMOUNT_OVERFLOW; 源数据缺失 → 标记"待补数据" |
| L5 数据一致 | 计费金额 = 规则公式(业务量); 计费明细可追溯到源业务单据; 月度汇总 = 明细之和 |
| L8 权限 | 系统自动执行; 仓库主管可手动触发重算 |
| L11 幂等 | 同一货主 + 同一计费周期重复计算 → 返回已有结果（不重复出账） |

#### US-M9-003 账单管理

| 维度 | 场景 |
|------|------|
| L4 错误路径 | 账单不存在 → M9_BILL_NOT_FOUND; 已确认账单不可修改 → M9_BILL_CONFIRMED; 账单金额与明细不符 → M9_AMOUNT_MISMATCH |
| L5 数据一致 | 账单状态（草稿/待确认/已确认/已结算）流转正确; 确认后不可回退 |
| L8 权限 | 仓库主管出账; 货主确认; 财务标记结算 |
| L11 幂等 | 账单确认/结算支持 Idempotency-Key; 重复确认 → 返回当前状态 |
