# 用户故事：M10 高级物流与运输协同（TMS+）

> 模块：M10 tms-plus
> 波次：Wave 5
> 依赖：M4 出库、M5 冷链、H5 快递

---

## US-M10-001：配送路径优化

**作为** 仓库主管
**我要** 根据门店经纬度自动规划最优配送路线
**以便** 减少运输成本和时间

### 验收标准

1. 输入：当日待配送门店列表（地址/经纬度）
2. 算法：按距离/时间窗/车辆容量规划路线（可对接第三方地图 API）
3. 输出：车辆 → 门店顺序 → 预计到达时间
4. 支持手动调整路线
5. 路线规划记录写入审计追踪

---

## US-M10-002：在途温控

**作为** 系统（自动）
**我要** 接收运输途中的温湿度数据，超标时预警
**以便** 冷链运输全程可追溯

### 验收标准

1. 对接冷藏车温度探头（GPS + 温度数据回传）
2. 在途温度关联到出库订单
3. 超标预警 → 企业微信通知
4. 到达后自动生成温控记录（可打印温控曲线二维码随货）
5. 数据保留 ≥ 5 年

---

## US-M10-003：容器回收追踪

**作为** 仓库主管
**我要** 追踪可循环容器（保温箱/周转箱）的出库和回收状态
**以便** 防止容器流失

### 验收标准

1. 可循环容器出库时记录：去了哪个客户/门店、出库时间
2. 回收状态：待回收 → 已回收 → 已清洗 → 可复用
3. 超期未回收预警（可配置天数）→ 企业微信通知
4. 回收率统计报表
5. 容器回收写入审计追踪

---

## 跨故事约束

1. **审计追踪**：路线/温控/回收全链路审计
2. **冷链 GSP**：在途温控数据是合规证据
3. **容器（LPN）**：回收追踪复用 M1 容器管理
